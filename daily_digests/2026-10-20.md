## 1. SafeDriveVLA: Navigation-Conditioned World Model Dreaming for Conflict-Aware End-to-End Autonomous Driving

- **来源：** [arXiv](https://arxiv.org/abs/2610.20609) · [PDF](https://arxiv.org/pdf/2610.20609) · [Hugging Face](https://huggingface.co/papers/2610.20609)
- **发布日期：** 2026-10-14（近 7 天补充；超出严格窗口 6 天）
- **作者：** Shaoyuan Xie, Zihan Zhang, Jingxuan Wang, Jiashu Qu, Xiaoqing Liang, Lingdong Kong, Junchi Lu, Henrik I. Christensen, Qi Alfred Chen
- **机构/单位：** 1UC Irvine 2UC San Diego 3University of Cincinnati 4National University of Singapore
- **领域标签：** navigation, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** SafeDriveVLA 先显式预测 STRICT/CAUTIOUS/FALLBACK 驾驶模式，再用“严格执行导航指令”的 latent world-model rollout 判断该指令在当前场景是否安全。
- **核心 insight：** 仅把安全偏好写进 VLA 会让模型普遍保守；先想象严格执行指令的后果，再由独立 mode token 决定执行、谨慎执行或覆盖指令，能把 navigation following 与 conflict awareness 从同一动作解码中解耦。

### 方法要点

- 用专家轨迹的运动学规则为每帧生成 STRICT、CAUTIOUS、FALLBACK 标签，并在动作 token 前监督输出 mode token。
- 冻结 V-JEPA 2 ViT-L target encoder，以两帧编码运动信息，训练 action-conditioned Transformer 在 2.5 s、2 Hz 上预测 latent future。
- 将导航信号映射到 meta-command action anchor，沿该 anchor rollout 5 步；InternVL3-1B + LoRA 结合 dreamed latents，以 2048 个 motion primitives 和 lateral PID 输出轨迹。

| CARLA-F，纯自然语言指令，closed loop | Navigation Completion Rate (weighted Avg.) | 83.0% | best SimLingo variant 55.6% | +27.4pp；lane-change left/right 从 0/0 提至 63.6/72.4% | PDF p.8 Table 4；Avg. 排除 speed，按指令数加权。 |
| B2D-C，instruction-scene conflict | DS / SR / collisions / traffic violations / out-of-route | 85.9 / 67.3% / 38 / 9 / 4 | SimLingo-Safe 72.8 / 38.0% / 60 / 61 / 11 | +13.1 DS / +29.3pp SR；碰撞 -36.7%，交通违规 -85.2%，偏航 -63.6% | PDF p.9 Table 5。 |

## 2. ORD-WM: Learning Object-Centric Rigid Dynamics for 3D World Modeling in Robotic Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2610.23156) · [PDF](https://arxiv.org/pdf/2610.23156)
- **发布日期：** 2026-10-16（近 7 天补充；超出严格窗口 4 天）
- **作者：** Yueyang Weng, Xiaopeng Zhang, Yuxi Ou, Yongjin Mu, Chengzhi Zhao, Yanjie Li
- **机构/单位：** Harbin Institute of Technology, Shenzhen
- **领域标签：** manipulation, world_models
- **灵巧手相关：** 否
- **一句话概括：** ORD-WM 把每个刚体编码为 SDF-supervised vector-neuron latent，并只预测 object-wise SE(3) 增量，以解析刚体变换在 latent 中滚动，从结构上消除长时 shape drift。
- **核心 insight：** 对 rigid manipulation，世界模型不必逐点生成未来几何；把 geometry 作为持久 object state、把 dynamics 限制为 object-level SE(3) update，既能保证形状不漂移，又能把 rollout 做到足以支撑实时 CEM-MPC。

### 方法要点

- 从多视角 RGB-D 经 SAM 3 mask 与 back-projection 构建 object-centric point clouds。
- 用 SDF-VNVAE 将物体编码成可随 SO(3) 等变变换的 3D vector-feature latent，decoder 以 query point 预测 SDF。
- Transformer dynamics model 结合 floating/fixed object、gripper state 与 action tokens，预测每个 floating object 的 translation 与 6D rotation increment，并解析应用到 latent 与 center。
- 用 CEM 在 latent space rollout 候选 action sequences，只执行首个 action 后重观测并 receding-horizon replan。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| LIBERO held-out multi-step rollout，full trajectory | moving/static point L2 / shape-consistency CD | ORD-WM 37.60 / 8.50 / 0.00 mm | PointWorld(ft) 225.68 / 18.84 / 3.58 mm | moving -83.3%，static -54.9%，shape drift 消除 | PDF p.6 Table 1；各列均为 mm。 |
| 约 170-step rollout ablation | Full-trajectory Surface CD / Shape Consistency CD / rollout FPS(B=1) | 4.729 mm / <0.05 mm residual / 784 FPS | w/o SE(3) update 131.600 / 4.683 mm / 902 FPS | Surface CD -96.4%，以少量吞吐换结构化几何一致性 | PDF p.7 Table 2；0† 表示构造保证，数值 residual <0.05 mm。 |
| 真实 Franka pushing MPC，1024 candidates×8-step sequence | Success Rate / final position error / planning time | 90% / 0.972 cm / 269.9 ms | 256 candidates: 70% / 1.64 cm / 115.7 ms | +20pp，error -40.7%，planning +154.2 ms | PDF p.8 Table 3；成功阈值 final error <2 cm，单 RTX 3090。 |

- **为什么值得读：** 这是一个很干净的 inductive-bias 例子：不靠更大生成模型，而是用 rigid-body structure 同时解决 rollout 稳定性与规划速度。
- **我的看法：** 优点是几何一致性由构造保证、ablation 清楚、真实闭环 MPC 延迟有量化；不足是只覆盖 floating/fixed rigid bodies，质量/摩擦/contact constraints 未显式建模，依赖准确分割与深度，训练分布和真实任务规模仍小。

## 3. WAVE-0: Bridging VLA Policies and WAMs with Lightweight Latent Future Prediction

- **来源：** [arXiv](https://arxiv.org/abs/2610.18568) · [PDF](https://arxiv.org/pdf/2610.18568) · [Hugging Face](https://huggingface.co/papers/2610.18568)
- **发布日期：** 2026-10-13（近 7 天补充；超出严格窗口 7 天）
- **作者：** Haomin Wang, Anqiong Ji, Ke Wang, Zhongshan Liu, Ru Ying, Ran Zheng, Zhipeng Zhang
- **机构/单位：** 1AutoLab, School of Artificial Intelligence, Shanghai Jiao Tong University; 2Awaken Robotics 3Baidu AI Cloud 4Zhejiang University
- **领域标签：** manipulation, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** WAVE-0 让 VLM 先生成 latent action plan，经 257M latent world model 预测未来视觉表征，再把 future tokens 直接喂给 π0.5 action expert，而无需生成像素视频。
- **核心 insight：** 未来预测只有在 inference 时真正条件化动作生成才充分发挥价值；用真实机器人 action 训练 latent dynamics，再用 counterfactual mismatched action 排序约束，可避免从视觉变化反推动作和大规模视频预训练。

### 方法要点

- Stage 1：冻结 π0.5 SigLIP，把当前/未来图像压成 4×4 tokens；action/state encoders 与 12-layer Transformer 预测 latent residual。
- future cosine loss + residual SmoothL1 + mismatched-action counterfactual ranking loss，使预测对可执行动作敏感。
- Stage 2：PaliGemma VLM 的 learnable queries 生成 latent action plan；冻结 world model 预测未来，resampler 压成 12 tokens，显式条件化 flow-matching action expert。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| RoboTwin 2.0，2,500 clean + 25,000 randomized demos，50 tasks | clean / randomized / average success | 91.46% / 91.48% / 91.47% | π0.5 81.12% / 79.64% / 80.38% | +10.34/+11.84/+11.09pp | PDF p.6 Table 1(b)。 |
| LIBERO-Plus / LIBERO-Pro / LIBERO-Para zero-shot OOD | success rate | 88.0% / 61.4% / 75.0% | π0.5 84.5% / 53.0% / 71.4% | +3.5/+8.4/+3.6pp | PDF p.7 Table 2 与邻近正文；LIBERO-Para 数值来自正文。 |
| AgileX Piper 真机三任务，每任务 200 demos、20 trials | average success rate | 73.3% | π0.5 38.3%；best other baseline LaWAM 43.3% | +35.0pp vs π0.5；+30.0pp vs LaWAM | PDF p.7 Table 3；Book/USB/Keyboard 为 85/65/70%。 |
| 真机服务端 inference | mean latency | 305.9 ms | π0.5 287.1 ms；ImageWAM 582.6 ms | +18.8 ms vs π0.5；比 ImageWAM 低 47.5% | PDF p.15 Table 11；不同模型大小与 action chunk 不完全一致。 |

### 复现可行性

| Code | Model | Data | Hardware / simulator | Difficulty | 最现实路径 |
|---|---|---|---|---|---|
| 已公开：https://github.com/AutoLab-SAI-SJTU/WAVE-0；项目页提供结果与资源。 | π0.5/PaliGemma/SigLIP；257M trainable latent world model，完整 WAVE-0 约 4.3B。 | LIBERO 1,693 trajectories/273,465 frames；RoboTwin 27,500 demos；真机每任务 200 demos。 | RoboTwin 两阶段训练约 670 H100 GPU-hours；真机 dual-arm AgileX Piper；服务端 latency 配置见 Appendix。 | 极高 | 用公开仓库先复现 π0.5、π0.5+WM auxiliary 与 WAVE-0 三点消融；资源有限时在 LIBERO 单 suite 缩小 Stage 1，确认 counterfactual ranking 和 future conditioning 后再扩展。 |

- **为什么值得读：** 它给昂贵 video WAM 一个务实替代：不生成未来像素，但让动作解码器在训练和推理时都真正看见预测未来。
- **我的看法：** 优点是跨仿真/OOD/真机证据强、训练样本和 latency 均量化、代码公开；不足是仍需昂贵 H100 训练，真实任务各自单独训练，4.3B 模型的绝对延迟仍高于 π0.5。

## 4. MambaAct: Efficient Mamba Action Experts for Flow-Matching Vision-Language-Action Models

- **来源：** [arXiv](https://arxiv.org/abs/2610.22951) · [PDF](https://arxiv.org/pdf/2610.22951)
- **发布日期：** 2026-10-16（近 7 天补充；超出严格窗口 4 天）
- **作者：** Khuyen Pham, Tran Nguyen Le, Edoardo Fazzari, Cesare Stefanini
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** MambaAct 保留 π0.5 的 pretrained vision-language prefix encoder，只把反复执行的 311.5M Transformer action expert 换成 29.7M Mamba expert，并用压缩 context 与 gated FiLM 做条件注入。
- **核心 insight：** flow-matching VLA 的主要延迟来自多次 denoising 中重复调用 action expert；把压缩焦点放在这一重复路径，而非牺牲 VLM 或减少 sampling steps，可获得约 10× expert compression，同时维持甚至提升控制成功率。

### 方法要点

- 将 π0.5 visual/language prefix tokens 投影并分段池化，另以 learned queries 提取 global summaries，形成可在各 denoising step 复用的 compact context。
- 用 SISO Mamba3 沿 action-token sequence 建模 noisy continuous actions，通过 gated FiLM scale/shift 调制每个 Mamba block，避免重复 token-level cross-attention。
- 保留标准 10-step flow matching 与 pretrained VLM joint fine-tuning，不需要 teacher、额外 pretraining 或 distillation；另验证 VLM L12 组合压缩和迁移到 SmolVLA。

### 实验与结果

|---|---|---|---|---|---|
| LIBERO，3 fine-tuning seeds，50 trials/task，单 H100 | Average Success / denoise latency / E2E latency | 97.80±0.43% / 56.40 ms / 107.6 ms | π0.5 96.72±0.14% / 160.26 ms / 228.6 ms | +1.08pp；denoise -64.8%，E2E -52.9% | PDF p.5 Table I；核对 success 与 latency 两个表块。 |
| LIBERO-Plus zero-shot shifts | Total robustness score | 79.7% | matched π0.5 78.7% | +1.0pp；robot-initial-pose 70.9%→77.6% | PDF p.6 Table III。 |
| 真实 UR5 nut pouring，RTX 5090 | OOD / final success / denoise latency | 95.2% / 96.9% / 30.84 ms | π0.5 86.5% / 91.3% / 74.82 ms | +8.7/+5.6pp；denoise -58.8% | PDF p.7 Table IV。 |
| SmolVLA transfer，LIBERO，2,000 episodes | Average Success / E2E latency / expert params | 84.95% / 90.61 ms / 64.31M | released SmolVLA 81.30% / 188.69 ms / 98.25M | +3.65pp；E2E -52.0%，expert -34.5% | PDF p.8 Table VIII；同为 25k-step/batch-32 对照。 |

- **为什么值得读：** 它精准瞄准 flow-matching VLA 最贵的重复计算模块，并用跨 backbone、跨压缩轴和真实任务证明 action-expert replacement 是独立有效的效率轴。
- **我的看法：** 优点是多 seed、真实 latency、公开权重与详细 mixer/conditioning ablation；不足是真机仅两个 UR5 tasks，gated conditioning 的提升与 expert size 有混杂，尚未验证和 token pruning、single-step denoising 的组合。

## 5. VLA-Fabric: Learning Interaction for Composable Multi-Arm VLA Agents

- **来源：** [arXiv](https://arxiv.org/abs/2610.23018) · [PDF](https://arxiv.org/pdf/2610.23018) · [Hugging Face](https://huggingface.co/papers/2610.23018)
- **发布日期：** 2026-10-16（近 7 天补充；超出严格窗口 4 天）
- **作者：** Chenglong Zhang, Shuaijun Liu, Feiyang You, Shuyang Hao, Chengyu Wu, Ningxin Su
- **机构/单位：** 1The Hong Kong University of Science and Technology (Guangzhou); Project Website: nebulis-lab.com/VLA-Fabric
- **领域标签：** embodied_ai, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** VLA-Fabric 把每条机械臂保留为完整 arm-local VLA，通过 shared semantic context、peer latent K/V 与 action-stage interaction 三类显式接口，让 2–4 个 π0.5/SingleVLA agents 协同。
- **核心 insight：** 多臂扩展不一定要把动作空间合成一个越来越大的 centralized policy；更可组合的做法是保持本地感知与 action ownership，只在语义、latent 和 action intent 三个计算边界交换 peer representations，而交互价值随物理耦合强度增加。

### 方法要点

- 从可分解的 TwinVLA/SingleVLA 出发，系统搜索 interaction entry、Common aggregation、Private K/V、action fusion 与 common-first adaptation。
- 把选出的三个 coordination functions 迁移到 π0.5：18 层内同步 Common multimodal prefix，receiver-local Action Expert query 读取 peer Private Prefix K/V，并在每层/每个 flow step 接收 gated peer-action residual。
- 扩展到 N agents 时保持每个 local action head 维度不变，按 role order 聚合 peer contexts；每项 team/task 进行独立 fine-tuning。
