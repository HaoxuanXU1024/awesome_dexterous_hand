## 2. Modeling What Changes: Sparse, Residual World Models for Object-Centric Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2609.02046) · [PDF](https://arxiv.org/pdf/2609.02046)
- **发布日期：** 2026-09-02（近 7 天补充；超出严格窗口 2 天）
- **作者：** Param Thakkar, Parsika Paresh Shah, Manisha Sushant Gote
- **机构/单位：** Veermata Jijabai Technological Institute; Arizona State University; ZuiGO Private Limited
- **领域标签：** manipulation, world_models
- **灵巧手相关：** 否
- **一句话概括：** 该工作只预测场景中发生变化的 object-centric 状态，并用 sparse residual world model 降低计算和误差传播。
- **核心 insight：** 在 MuJoCo tabletop pushing 中，change gating 让模型避免重复预测静态物体，同时保持跨 object count 的迁移能力。

### 方法要点

- 用 change detector 选择发生变化的 object slots。
- 仅对 movers 预测 residual dynamics，静态对象保持不变。
- 将模型接入 cross-entropy sampling planner，评估模型预测是否足以支持规划。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| MuJoCo tabletop pushing，3-8 objects | mover next-state pose L2 | 比 dense MLP 准确 2.5-4.6 倍 | dense multilayer perceptron | 2.5-4.6x accuracy; 需核对表头定义 | PDF Abstract/Section V。 |
| 8 objects | change-detection F1 | 0.80-0.87 | dense baseline degenerate | 无法按同一有效 baseline 计算 | PDF Abstract、Table II/Section V。 |
| cross-count transfer | F1 retention | 99.4% | same model without retraining | retention | PDF Abstract/Section V。 |
| planner, three seeds | success | 0.23 ± 0.06 | dense monolith 0 at every seed; oracle 1.00 | 相对 dense 为非零 vs 0 | PDF planning table/Section VII；需人工核对表号。 |

- **灵巧手相关：** 否
- **一句话概括：** HINT 在 manipulation-pattern transition 时进行稀疏语义推理，并持续跟踪目标后将意图注入 VLA action policy。
- **核心 insight：** 把高层语义决策与连续控制解耦：只在模式切换时重推理，期间靠 tracking、visual highlighting 和 attention prior 维持目标一致性。

- 在 pattern transition 触发 semantic reasoning，解析当前 subtask 与 target。
- 通过 multi-view grounding 与 continuous visual tracking 保持目标绑定。
