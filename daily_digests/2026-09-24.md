## 1. Think Like a World Model, Act Like a VLA: Distilling World-Model Representations into Compact Robot Policies

- **来源：** [arXiv](https://arxiv.org/abs/2609.24682) · [PDF](https://arxiv.org/pdf/2609.24682) · [Hugging Face](https://huggingface.co/papers/2609.24682)
- **发布日期：** 2026-09-21（近 7 天补充；超出严格窗口 3 天）
- **作者：** Trung Dao, Sankalp Yamsani, Jaden Park, Joohyung Kim, Yong Jae Lee
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** dexterous, humanoid, manipulation, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** THAW-VLA 用冻结 world model 的离线缓存视觉特征监督小型 VLA，仅增加训练期 cosine alignment，就在不改变部署网络和推理成本的前提下提升操控成功率。
- **核心 insight：** world model 的物理先验可以从其内部表征中蒸馏，而不必把昂贵的未来生成过程带进控制环；离线缓存 teacher feature 使训练时也无需加载 teacher。

### 方法要点

- 保留 QwenGR00T student 的 flow-matching action loss，从每个相机视角的末层 image tokens 做 mean pooling。
- 用两层 MLP 将 student pooled feature 投影到 Cosmos3-Nano layer-24 feature，以 cosine loss 对齐，权重固定为 0.5。
- teacher 对训练帧只前向一次并写入 memory-mapped cache；训练结束丢弃 projector，部署仍是原 student 的一次 backbone prefill 加四步 flow。

## 2. MATE: Multi-Agent Virtual Teleoperation Platform for Humanoid Collaboration Data Collection

- **来源：** [arXiv](https://arxiv.org/abs/2609.26520) · [PDF](https://arxiv.org/pdf/2609.26520)
- **发布日期：** 2026-09-22（近 7 天补充；超出严格窗口 2 天）

- **核心 insight：** 多人协作数据的核心不是把单机轨迹拼在一起，而是保留同一物理时钟下的因果耦合；长序列训练还需优先采样接触、交接、角色切换等真正推动执行的窗口。

- EAIS 在 40-step 窗口的前 20 steps 内自动计算 task progress、motion-mode switch、action magnitude、object change 与 contact 信号，按进展和交互重要性加权采样。

## 3. Imperfection for Precision: Upcycling Imperfect Data for High-Precision Robotic Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2609.26672) · [PDF](https://arxiv.org/pdf/2609.26672)
- **发布日期：** 2026-09-22（近 7 天补充；超出严格窗口 2 天）
- **作者：** Hao Wei, Yang Liu, Chao Tang, Shengbao Li, Jiangtao Chen, Jinxuan Zhu, Jiaheng Wang, Hong Yin, Zhaofeng Cao, Tingguang Li
- **机构/单位：** 1Samsung Robotics eXperience 2National University of Singapore 3University of Illinois Urbana-Champaign
- **领域标签：** manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** ε4P 按 flow time 把低精度同任务数据限制在高噪声区、把高精度异任务数据限制在低噪声区，让原本有害的 imperfect data 转为高精度操控增益。
- **核心 insight：** imperfect data 的价值不是全局好坏，而取决于 flow trajectory 上 action 与 context 各自主导的位置；因此应控制它在哪里贡献，而不仅是给多少权重。

### 方法要点

- 对同任务低精度数据 Dpm，训练 flow-time-conditioned source classifier；当 noised action 的 held-out AUC 接近 0.5 时确定 tpm，仅在 [tpm,1] 使用。
- 对异任务高精度数据 Dtm，置换 action/context 测量 policy sensitivity；以 action reliance 与 context reliance 的交点确定 ttm，仅在 [0,ttm] 使用。
- 高质量目标数据 Dpt 覆盖完整 [0,1]；模型结构、source sampling distribution 和标准 flow-matching objective 均不变。

| ATX admission-region control | success rate | Dpm [tpm,1]: 73.3%；Dtm [0,ttm]: 71.7% | Dpm native/opposite: 33.3%/30.0%；Dtm native/opposite: 43.3%/46.7% | 相对 native +40.0 与 +28.4 个百分点 | PDF p.6 Table IV；核对 admission interval 列 |

## 4. Grounded Action Model: 3D Grounding as a Foundation for Robotics

- **来源：** [arXiv](https://arxiv.org/abs/2609.23863) · [PDF](https://arxiv.org/pdf/2609.23863) · [Hugging Face](https://huggingface.co/papers/2609.23863)
- **发布日期：** 2026-09-20（近 7 天补充；超出严格窗口 4 天）
- **作者：** Gehao Zhang, Weikai Huang, Shailesh Shailesh, Yiyan Peng, Jiafei Duan, Ranjay Krishna
- **机构/单位：** 1Northwestern University 2University of Washington 3National University of Singapore 4Microsoft
- **领域标签：** dexterous, foundation_models, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** Grounded Action Model 以冻结 promptable 3D detector 将语言、点击或框统一成目标物体的视觉与 metric geometry tokens，再用多流 transformer 预测动作块。
- **核心 insight：** 若基础模型显式回答哪个物体、在哪里、占多大空间，就能把无关背景挡在 policy observation 之外，并让目标重定位或替换直接反映在输入中。

### 方法要点

- WildDet3D 接收 language/2D point/2D box，输出目标 2D/3D boxes、metric depth 与 backbone feature；CoTracker3 维持跨帧关联。
- image tokens 仅保留目标框和 robot-arm silhouette；detection tokens 编码 point cloud、中心、尺度、旋转与 2D box，另加入 state-history。
- MM-DiT 以 language embedding 条件化，通过 flow matching 预测 absolute joint-position chunk，grounding backbone 保持冻结。

## 5. SafeLoop: Risk-Aware Rollback for Vision-Language-Action Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2609.26313) · [PDF](https://arxiv.org/pdf/2609.26313)
- **发布日期：** 2026-09-22（近 7 天补充；超出严格窗口 2 天）
- **作者：** Zeyu Lou, Tianran Zhang, Xinquan Yue, Ya Jing, Chenyang Si
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** SafeLoop 在不改 VLA 权重的前提下，用异步 hazard predictor、低频三动作 decider 和 safe-waypoint rollback 为长时操控增加主动安全恢复。
- **核心 insight：** 风险监测只有与可恢复动作结合才真正有用；回滚到尚可恢复的历史关节配置，再让 stochastic VLA 重采样，比在危险状态原地 stop 或 resample 更有效。

### 方法要点

- risk predictor 从多视角 RGB、proprioception 与 proposed action 预测 body/object hazard probability 及 normalized time-to-hazard，共四维 risk vector。
- simulation oracle 或人工标注 rollout，按短窗口构造稀有 hazard supervision；轻量 meta-policy 以 PPO 学习 noop、record、rollback。
- record 保存安全关节 waypoint；rollback 用 motion planning 回到最近安全点，清空当前执行并重新查询冻结 base VLA；风险预测异步、决策低频运行。

## 6. RouteRLT: Learning When and Which RL Specialist Should Control a Vision-Language-Action Policy

- **来源：** [arXiv](https://arxiv.org/abs/2609.26467) · [PDF](https://arxiv.org/pdf/2609.26467)
- **发布日期：** 2026-09-22（近 7 天补充；超出严格窗口 2 天）
- **作者：** Chongyu Zhu, Jaden Hinds, Hyegang Kim, Juan Sebastian Rojas, Ramy Elmallah, Chi-Guhn Lee
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** foundation_models, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** RouteRLT 从冻结 SmolVLA 的内部 latent 学习何时以及由哪个 phase-specific RL specialist 接管，并在 controller 切换时立即丢弃旧 action chunk 的未执行后缀。
- **核心 insight：** 精密阶段只占长轨迹的一小段，保持 generalist 处理其擅长的部分、把 RL 预算集中到 pickup/insertion，并学习无 privileged state 的接管时机，比全轨迹 RL 更稳。

### 方法要点

- 向 VLA prefix 加 learned token，训练 decoder 重建 prefix 后丢弃 decoder，冻结 encoder 得到 compact state zt。
- 每个 RL specialist 以 zt、proprioception 和 VLA reference chunk 为输入，离线到在线训练，稀疏 terminal reward 并带 reference deviation/smoothness penalty。
- causal phase classifier 输出 controller posterior，stabilizer 抑制瞬时切换；action-boundary manager 在 ownership 改变时清空旧队列并立即查询新 controller。

| Trossen cable pickup + 1mm-clearance port insertion；matched full trajectories | pickup-to-fixture / final insertion success | RouteRLT: 65.0% / 35.0%（20 trials） | SmolVLA@35: 53.3% / 6.7%（30 trials） | final insertion +28.3 个百分点，约 5.2× | PDF p.7 Fig. 6 图中数值与图注 trial counts |

## 7. MAVP: Map-Aware Visuomotor Policies for Mobile Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2609.26378) · [PDF](https://arxiv.org/pdf/2609.26378)
- **发布日期：** 2026-09-22（近 7 天补充；超出严格窗口 2 天）
- **作者：** Jinhe Tang, Ruixiao Dai, Weiming Zhi
- **机构/单位：** 1School of Computer Science, The University of Sydney, Australia
- **领域标签：** manipulation
- **灵巧手相关：** 否
- **一句话概括：** MAVP 从示范重建共享静态 map，让 policy 预测 map-frame base pose targets，再由定位反馈控制器执行，从而减少移动操控中速度误差累积。
- **核心 insight：** 把 base action 表示成同一地图坐标系下的目标姿态，可把“要到哪里”与“用什么速度到达”分离；持续 localisation 让示范标签、policy pose input 与 controller feedback 始终共享空间参照。

### 方法要点

- 用 robot-arm projection 与 VGGT4D mask 去掉机器人/动态区域，跨示范 stereo images 经 LightGlue/COLMAP 重建共享 sparse static map。
- 执行时用 map matching 加 cuVSLAM visual odometry 得到 map-frame (x,y,yaw)，policy 同时预测 base-pose targets、arm joints 与 gripper actions。
- low-level controller 用 feedforward 加 pose-error feedback 跟踪 base targets；训练时向 pose input 加从离线 localisation 估计的 Gaussian noise，但 action labels 保持不变。
