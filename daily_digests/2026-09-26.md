## 1. Think Like a World Model, Act Like a VLA: Distilling World-Model Representations into Compact Robot Policies

- **来源：** [arXiv](https://arxiv.org/abs/2609.24682) · [PDF](https://arxiv.org/pdf/2609.24682) · [Hugging Face](https://huggingface.co/papers/2609.24682)
- **发布日期：** 2026-09-21（近 7 天补充；超出严格窗口 5 天）
- **作者：** Trung Dao, Sankalp Yamsani, Jaden Park, Joohyung Kim, Yong Jae Lee
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** dexterous, humanoid, manipulation, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** THAW-VLA 用冻结 world model 的离线缓存视觉特征监督小型 VLA，仅增加训练期 cosine alignment，就在不改变部署网络和推理成本的前提下提升操控成功率。
- **核心 insight：** world model 的物理先验可以从其内部表征中蒸馏，而不必把昂贵的未来生成过程带进控制环；离线缓存 teacher feature 使训练时也无需加载 teacher。

### 方法要点

- 保留 QwenGR00T student 的 flow-matching action loss，从每个相机视角的末层 image tokens 做 mean pooling。
- 用两层 MLP 将 student pooled feature 投影到 Cosmos3-Nano layer-24 feature，以 cosine loss 对齐，权重固定为 0.5。
- teacher 对训练帧只前向一次并写入 memory-mapped cache；训练结束丢弃 projector，部署仍是原 student 的一次 backbone prefill 加四步 flow。

## 2. MemBodied: Recurrent Associative Memory for Vision-Language-Action Models

- **来源：** [arXiv](https://arxiv.org/abs/2609.28256) · [PDF](https://arxiv.org/pdf/2609.28256) · [Hugging Face](https://huggingface.co/papers/2609.28256)
- **发布日期：** 2026-09-23（近 7 天补充；超出严格窗口 3 天）
- **作者：** Tej Deep Pala, Navonil Majumder, Bryce Goh, Raphael Yee, Jianfei Yang, Liming Chen, Soujanya Poria
- **机构/单位：** 1Nanyang Technological University 2Griffin Labs 3 ´Ecole Centrale de Lyon; /githubCode:https://github.com/declare-lab/MemBodied; /gl⌢beProject Website:https://declare-lab.github.io/MemBodied
- **领域标签：** embodied_ai, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** MemBodied 以固定大小的逐层 associative matrices 记录 action→视觉后果，并用独立 initial-scene anchor 保存初始布局，从而让 VLA 获得不随 episode 增长的记忆。
- **核心 insight：** 交互历史和初始场景承担不同记忆职责：delta-rule state 适合持续更新 episode 进展，固定 anchor 则防止早期细节被反复写入覆盖。

### 方法要点

- 每个 action-network layer 维护 128×128 associative state；当前 state token 生成 query 读取 memory，结果注入专用 memory token。
- 执行 action chunk 后，将该动作与下一帧视觉后果组成 value，以 retention/write gates 的 delta rule 因果写回 memory。
- 首帧各相机 16×16 patch 压缩为 4×4 anchor；当前 state 通过 rank-64 cross-attention 选择性检索，sequence training 让后续 action loss 反传到早期写入。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| RMBench 5 个 memory-dependent tasks；每任务 50 rollouts，π0 backbone | 五任务 mean success rate | MemBodied: 50.0% | π0-Stateless: 6.4%；vanilla recurrent: 16.8%；NativeMEM: 38.4% | +43.6 / +33.2 / +11.6 个百分点 | PDF p.7 Table 1 与 Fig. 2(a)；核对五任务各列和均值 |
| NativeMEM 同一评测配置 | inference latency / peak GPU memory / added parameters | MemBodied: 129ms / 18.6GiB / 40M | NativeMEM: 1594ms / 20.6GiB / 415M | 延迟 -91.9%，峰值显存 -9.5%，新增参数约 1/10 | PDF p.7-8 Fig. 2(b) 与 Sec. 5.2 正文 |
| LIBERO 四套件；每套件 500 rollouts，共 2,000/checkpoint | Long / four-suite mean success rate | MemBodied: 90.6% / 95.1% | π0: 85.2% / 94.2% | Long +5.4 点；均值 +0.9 点 | PDF p.8 Table 2；核对 Spatial/Object/Goal/Long/Mean 表头 |

## 3. Grounded Action Model: 3D Grounding as a Foundation for Robotics

- **来源：** [arXiv](https://arxiv.org/abs/2609.23863) · [PDF](https://arxiv.org/pdf/2609.23863) · [Hugging Face](https://huggingface.co/papers/2609.23863)
- **发布日期：** 2026-09-20（近 7 天补充；超出严格窗口 6 天）
- **作者：** Gehao Zhang, Weikai Huang, Shailesh Shailesh, Yiyan Peng, Jiafei Duan, Ranjay Krishna
- **机构/单位：** 1Northwestern University 2University of Washington 3National University of Singapore 4Microsoft
- **领域标签：** dexterous, foundation_models, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** Grounded Action Model 以冻结 promptable 3D detector 将语言、点击或框统一成目标物体的视觉与 metric geometry tokens，再用多流 transformer 预测动作块。
- **核心 insight：** 若基础模型显式回答哪个物体、在哪里、占多大空间，就能把无关背景挡在 policy observation 之外，并让目标重定位或替换直接反映在输入中。

### 方法要点

- WildDet3D 接收 language/2D point/2D box，输出目标 2D/3D boxes、metric depth 与 backbone feature；CoTracker3 维持跨帧关联。
- image tokens 仅保留目标框和 robot-arm silhouette；detection tokens 编码 point cloud、中心、尺度、旋转与 2D box，另加入 state-history。
- MM-DiT 以 language embedding 条件化，通过 flow matching 预测 absolute joint-position chunk，grounding backbone 保持冻结。

## 4. AdaHVLA: Adaptive Harnesses for Long-Horizon Vision-Language-Action Execution

- **来源：** [arXiv](https://arxiv.org/abs/2609.29204) · [PDF](https://arxiv.org/pdf/2609.29204)
- **发布日期：** 2026-09-24（近 7 天补充；超出严格窗口 2 天）
- **作者：** Junyi Tang, Jie Peng, Zezhen Ding, Yuan Shen, Tianlong Chen
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** AdaHVLA 不改 VLA 权重，而用多智能体从机器人 rollout 中提出、打补丁并验证可执行 coordination harness，通过 revision graph 与 adaptation memory 累积长程执行经验。
- **核心 insight：** 长程失败往往来自 goal progress、visual buffer、recovery 与 completion 的编排，而非局部 VLA 动作本身；把这些机制做成可编辑代码，并要求每个修改先声明可观测行为假设再用 rollout 归因，可复用已有 VLA 而获得持续改进。

### 方法要点

- harness 维护 task progress、instruction/context、visual refresh、recovery 与 completion state，在每个决策边界调用固定 VLA 执行局部动作。
- analysis、revision、behavioral assessment 使用分离上下文；每个 patch 绑定 testable hypothesis，并以触发/提前分岔 attribution gate 判断观测证据能否更新支持度。
- revision graph 保留候选分支、evidence 与 rollback；跨任务 adaptation memory 压缩已验证协调问题和修改，但新任务重置 runtime state 与局部探索深度。
