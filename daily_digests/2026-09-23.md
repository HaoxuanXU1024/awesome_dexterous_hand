## 1. Think Like a World Model, Act Like a VLA: Distilling World-Model Representations into Compact Robot Policies

- **来源：** [arXiv](https://arxiv.org/abs/2609.24682) · [PDF](https://arxiv.org/pdf/2609.24682) · [Hugging Face](https://huggingface.co/papers/2609.24682)
- **发布日期：** 2026-09-21（近 7 天补充；超出严格窗口 2 天）
- **作者：** Trung Dao, Sankalp Yamsani, Jaden Park, Joohyung Kim, Yong Jae Lee
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** dexterous, humanoid, manipulation, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** THAW-VLA 用冻结 world model 的离线缓存视觉特征监督小型 VLA，仅增加训练期 cosine alignment，就在不改变部署网络和推理成本的前提下提升操控成功率。
- **核心 insight：** world model 的物理先验可以从其内部表征中蒸馏，而不必把昂贵的未来生成过程带进控制环；离线缓存 teacher feature 使训练时也无需加载 teacher。

### 方法要点

- 以 0.8B QwenGR00T 为 student，保留原有 flow-matching action loss；从每个相机视角的 student image tokens 做 mean pooling。
- 用两层 MLP 将 student pooled feature 投影到 Cosmos3-Nano understanding tower 的 layer-24 feature 维度，以 cosine loss 对齐，权重固定为 0.5。
- teacher 对训练帧只前向一次，按 trajectory/base-index 写入 memory-mapped cache；训练结束丢弃 projector，部署仍是原 student 的一次 backbone prefill 加四步 flow。

## 2. StenoVLA-3D: 3D-Aware Reasoning VLA for Navigation Through Gastrointestinal Stenoses

- **核心 insight：** 内镜导航不仅需要当前画面动作，还需要显式几何来安全穿越狭窄，并用 persistent memory 保留已离开视野的病灶；消融显示这两项对物理流程成功是必要条件。

- temporal branch 跟踪穿越阶段，persistent lesion memory 保存 polyp/ulcer/stenosis 证据；独立 shape/report heads 输出开口形状与最终病灶总结。

## 3. Bridge3D: Enabling Vision-Language-Action Models to See and Act in 3D

- **来源：** [arXiv](https://arxiv.org/abs/2609.24525) · [PDF](https://arxiv.org/pdf/2609.24525)
- **发布日期：** 2026-09-21（近 7 天补充；超出严格窗口 2 天）
- **作者：** Haoxuan Li, Sixu Yan, Lianghui Zhu, Xuanlai Tang, Shikang Wang, Xinggang Wang
- **机构/单位：** 1Huazhong University of Science and Technology
- **领域标签：** foundation_models, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** Bridge3D 用 VGGT residual fusion 修补 VLA 的 3D 感知，再让 action hidden states 直接 cross-attend 带语义的原始 3D point field，以显式几何约束动作去噪。
- **核心 insight：** 把 3D 只融合进视觉 token 仍不足以保证精确动作；感知侧的 Implicit Fusion 与动作侧的 Explicit Conditioning 互补，而且应只插入线性探针显示空间信息开始退化的 DiT blocks。

### 方法要点

- 多视角 RGB 同时进入 VLM 与冻结 VGGT，patch-level 3D token 经轻量 residual adapter 加到 VLM visual tokens。
- 由 RGB-D point cloud 与语义 mask 构建未压缩的 3D semantic field；action query/key 加 3D RoPE，动作 hidden states cross-attend 原始 point-wise geometry/semantics。
- 冻结 action backbone 做 layer-wise end-effector coordinate linear probing，定位 blocks #7-11 的空间退化，只在这些层加入 Explicit Conditioning。

## 4. Grounded Action Model: 3D Grounding as a Foundation for Robotics

- **来源：** [arXiv](https://arxiv.org/abs/2609.23863) · [PDF](https://arxiv.org/pdf/2609.23863) · [Hugging Face](https://huggingface.co/papers/2609.23863)
- **发布日期：** 2026-09-20（近 7 天补充；超出严格窗口 3 天）
- **作者：** Gehao Zhang, Weikai Huang, Shailesh Shailesh, Yiyan Peng, Jiafei Duan, Ranjay Krishna
- **机构/单位：** 1Northwestern University 2University of Washington 3National University of Singapore 4Microsoft
- **领域标签：** dexterous, foundation_models, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** Grounded Action Model 以冻结 promptable 3D detector 将语言、点击或框统一成目标物体的视觉与 metric geometry tokens，再用多流 transformer 预测动作块。
- **核心 insight：** 机器人基础模型若从预训练阶段就显式回答‘哪个物体、在哪里、占多大空间’，就能把无关背景挡在 policy observation 之外，并让目标重定位或目标替换直接反映在输入中。

### 方法要点

- WildDet3D 接收 language/2D point/2D box prompt，输出目标对象 2D/3D boxes、dense metric depth 与 backbone feature；部署时 CoTracker3 维持对象关联。
- image tokens 只保留目标框与 robot-arm silhouette 覆盖区域；detection tokens 编码目标 point cloud、中心、尺度、旋转与 2D box，另加入 state-history token。
- 12-block MM-DiT 以 language embedding 做 adaptive layer norm conditioning，并用 flow matching 预测 absolute joint-position action chunk；grounding backbone 始终冻结。

## 5. Zeva-Ego: Egocentric Mid-Training with In-Context Causal Learning for Robot Manipulation

- **领域标签：** embodied_ai, manipulation, vla

### 方法要点

- 将人手 wrist/fingertips 与机器人 end-effector 统一为 camera-frame pose+virtual gripper action chunks，所有未来动作相对 chunk-start camera frame 表示。

## 6. CARE: Experience-Guided Atomic Corrective Execution for Vision-Language-Action Policies

- **来源：** [arXiv](https://arxiv.org/abs/2609.24118) · [PDF](https://arxiv.org/pdf/2609.24118) · [Hugging Face](https://huggingface.co/papers/2609.24118)

- **机构/单位：** 论文首页未可靠提取
- **领域标签：** manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** CARE 从真实执行失败拟合 stage-conditioned deviation distribution，生成针对性纠错示范，并用 3D monitor 在推理时触发 adjustment 或 re-operation。
- **核心 insight：** 失败不应只被回滚或随机扰动近似，而应作为结构化数据源：先学习 policy 实际会进入哪些失败状态，再训练同一 VLA 执行原子级纠正，并由物理几何 monitor 决定何时调用。

### 方法要点

- 先执行 nominal atomic plans 100 次，按 stage 记录 grasp/placement 临界事件的相对平移与 yaw deviation，拟合经验 failure distribution。
- 从该分布采样并在物理动态中展开到真实失败初始状态，采集 corrective demonstrations；训练数据量与 uniform/nominal 对照严格匹配。
- VLM planner 将长时任务拆成 atomic stages，SAM3+DA3 构建 3D 几何 predicate monitor；局部偏差触发 intra-execution adjustment，stage 失败触发 post-execution re-operation，同一个 VLA 执行全部指令。
