## 1. SafeDriveVLA: Navigation-Conditioned World Model Dreaming for Conflict-Aware End-to-End Autonomous Driving

- **来源：** [arXiv](https://arxiv.org/abs/2610.20609) · [PDF](https://arxiv.org/pdf/2610.20609) · [Hugging Face](https://huggingface.co/papers/2610.20609)
- **发布日期：** 2026-10-14（近 7 天补充；超出严格窗口 2 天）
- **作者：** Shaoyuan Xie, Zihan Zhang, Jingxuan Wang, Jiashu Qu, Xiaoqing Liang, Lingdong Kong, Junchi Lu, Henrik I. Christensen, Qi Alfred Chen
- **机构/单位：** 1UC Irvine 2UC San Diego 3University of Cincinnati 4National University of Singapore
- **领域标签：** navigation, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** SafeDriveVLA 先显式预测 STRICT/CAUTIOUS/FALLBACK 驾驶模式，再用“严格执行导航指令”的 latent world-model rollout 判断该指令在当前场景是否安全。
- **核心 insight：** 仅把安全偏好写进 VLA 会让模型普遍保守；先想象严格执行指令的后果，再由独立 mode token 决定执行、谨慎执行或覆盖指令，能把 navigation following 与 conflict awareness 从同一动作解码中解耦。

### 方法要点

- 用专家轨迹的运动学规则为每帧生成 STRICT、CAUTIOUS、FALLBACK 标签，并在动作 token 前监督输出 mode token。
- 冻结 V-JEPA 2 ViT-L target encoder，以两帧编码运动信息，训练 action-conditioned Transformer 在 2.5 s、2 Hz 上预测 latent future。
- 将导航信号映射到 meta-command action anchor，沿该 anchor rollout 5 步；InternVL3-1B + LoRA 结合 dreamed latents，以 2048 个 motion primitives 和 lateral PID 输出轨迹。

| CARLA-F，纯自然语言指令，closed loop | Navigation Completion Rate (weighted Avg.) | 83.0% | best SimLingo variant 55.6% | +27.4pp；lane-change left/right 从 0/0 提至 63.6/72.4% | PDF p.8 Table 4；Avg. 排除 speed，按指令数加权。 |
| B2D-C，instruction-scene conflict | DS / SR / collisions / traffic violations / out-of-route | 85.9 / 67.3% / 38 / 9 / 4 | SimLingo-Safe 72.8 / 38.0% / 60 / 61 / 11 | +13.1 DS / +29.3pp SR；碰撞 -36.7%，交通违规 -85.2%，偏航 -63.6% | PDF p.9 Table 5；相对下降为作者按 best SimLingo variant 计算。 |

## 2. AutoRSR: Automated Real-to-Sim-to-Real Data Generation for Scalable Robot Learning

- **来源：** [arXiv](https://arxiv.org/abs/2610.20336) · [PDF](https://arxiv.org/pdf/2610.20336)
- **发布日期：** 2026-10-14（近 7 天补充；超出严格窗口 2 天）
- **作者：** Jiawei Zhang, Chang Liu, Litao Deng, Tao Zhang, Qin Jin
- **机构/单位：** Scalable Robot Learning; Renmin University of China
- **领域标签：** embodied_ai, manipulation, robot_learning, sim_to_real
- **灵巧手相关：** 否
- **一句话概括：** AutoRSR 将多视角扫描、语义 3DGS、机器人坐标对齐、演示 retargeting 与 trajectory/domain randomization 串成自动 real-to-sim-to-real 数据流水线。
- **核心 insight：** 现实场景转仿真的主要成本不只是重建，而是对象级资产、metric robot-frame alignment 与可执行轨迹；把三者统一起来，少量参考运动就能扩成千级可训练 episode。

### 方法要点

- 手机与腕部 D405 混合扫描，COLMAP/PostShot 求相机位姿；SAM2 跨视角传播实例，ObjectGS 重建语义 Gaussian，SuGaR 生成 collision mesh。
- 用腕部相机—robot base 的标定姿态做 Sim(3) robust alignment，把重建空间、物体与人类演示映射到 metric robot frame。
- GroundingDINO+SAM2 跟踪目标，retarget 参考运动；在仿真中做轨迹插值与视觉 domain randomization，输出同步 image/proprioception/action episode。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| PiperX 真机三任务；AutoRSR 1,000 synthetic episodes vs 150 teleop demos；每策略每任务 15 trials | success rate | 73.3% / 80.0% / 86.7% | 150 teleop：73.3% / 86.7% / 86.7% | 0 / -6.7 / 0pp，均在 10pp 内 | PDF p.6 Table I；任务依次为 Pour into yellow bowl、Put duck on box、Close laptop。 |
| Pour task 数据混合 | success rate | 150 real + 1k sim = 86.7% | real-only 73.3%；sim-only 73.3% | +13.4pp | PDF p.6 Table II。 |
| trajectory / visual augmentation 消融 | success rate | 完整 73.3% | w/o trajectory augmentation 13.3%；弱 visual augmentation 60% | +60.0pp / +13.3pp | PDF p.6 Table III–IV；视觉消融是减弱而非完全关闭。 |
| 三场景坐标对齐 | mean error / RMSE | aligned 0.61–0.91 cm / 0.62–0.91 cm | raw reconstruction 3.81–8.62 cm / 3.95–9.07 cm | 各场景误差显著降低；不从范围值额外推算百分比 | PDF p.7 Table V；逐行核对 graspduck、pour、computer。 |

## 3. What Matters for World Modeling in Vision-Language-Action Models?

- **来源：** [arXiv](https://arxiv.org/abs/2610.19825) · [PDF](https://arxiv.org/pdf/2610.19825)
- **发布日期：** 2026-10-14（近 7 天补充；超出严格窗口 2 天）
- **作者：** Qisen Ma, Yixiang Chen, Yuan Xu, Peiyan Li, Jiabing Yang, Kai Wang, Jianhua Yang, Jianlou Si, Jun Huang, Jing Liu, Nianfeng Liu, Yan Huang et al.
- **机构/单位：** 1New Laboratory of Pattern Recognition (NLPR),; Institute of Automation, Chinese Academy of Sciences; 2School of Artificial Intelligence, University of Chinese Academy of Sciences
- **领域标签：** vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** 这项控制变量研究表明，VLA world modeling 没有统一赢家：2D semantic target 最稳，而 decoupled future expert/predictor 更适合动态、长时、低数据与 foundation VLA 迁移。
- **核心 insight：** world representation 与 integration paradigm 强耦合；把未来监督直接压进共享 VLM 特征可能破坏预训练先验，而独立预测流虽增加在线成本，却更能在分布移位和长时任务中保留 task-conditioned dynamics。

### 方法要点

- 在统一 Qwen3-VL-2B + cross-DiT baseline 下比较 WM-Align、WM-Query、WM-MoT、WM-Ext 四种 integration paradigm。
- 六类 frozen target encoder 使用相同未来帧与 cosine world loss：DINOv3、SigLIP、VGGT、ImageVAE、WanVAE、V-JEPA 2.1。
- 再把四种范式迁移到 π0.5，并在 LIBERO/Plus、RoboTwin 2.0、DOMINO 与 Franka 真机上测静态/动态、ID/OOD、数据规模和部署开销。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| Qwen backbone，LIBERO-Plus OOD | average success rate | WM-MoT 76.2% | action-only 71.8% | +4.4pp | PDF p.7 Table 1；WM-MoT 七种 perturbation 均改善。 |
| Qwen backbone，RoboTwin Clean2Clean 长时任务 | success rate | WM-Query 57.0% | action-only 30.7% | +26.3pp | PDF p.7 Table 2；horizon >300 steps。 |
| π0.5 adaptation，RoboTwin 2.0 | Clean2Clean / Clean2Random average success | WM-MoT 71.3% / 49.7%；WM-Ext 71.7% / 48.5% | π0.5 69.1% / 46.4% | WM-MoT +2.2/+3.3pp；WM-Ext +2.6/+2.1pp | PDF p.8 Table 4；WM-Align 反而降至 63.6%/41.0%。 |
| Franka Research 3，四真机任务，每任务每方法 40 trials | overall success rate | WM-MoT 73.8% | action-only 45.0% | +28.8pp | PDF Appendix Table C.8（p.29）；静态均值 82.5%，动态均值 65.0%。 |

## 4. WAVE-0: Bridging VLA Policies and WAMs with Lightweight Latent Future Prediction

- **来源：** [arXiv](https://arxiv.org/abs/2610.18568) · [PDF](https://arxiv.org/pdf/2610.18568) · [Hugging Face](https://huggingface.co/papers/2610.18568)
- **发布日期：** 2026-10-13（近 7 天补充；超出严格窗口 3 天）
- **作者：** Haomin Wang, Anqiong Ji, Ke Wang, Zhongshan Liu, Ru Ying, Ran Zheng, Zhipeng Zhang
- **机构/单位：** 1AutoLab, School of Artificial Intelligence, Shanghai Jiao Tong University; 2Awaken Robotics 3Baidu AI Cloud 4Zhejiang University
- **领域标签：** manipulation, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** WAVE-0 让 VLM 先生成 latent action plan，经 257M latent world model 预测未来视觉表征，再把 future tokens 直接喂给 π0.5 action expert，而无需生成像素视频。
- **核心 insight：** 未来预测只有在 inference 时真正条件化动作生成才充分发挥价值；用真实机器人 action 训练 latent dynamics，再用 counterfactual mismatched action 排序约束，可避免从视觉变化反推动作和大规模视频预训练。

### 方法要点

- Stage 1：冻结 π0.5 SigLIP，把当前/未来图像压成 4×4 tokens；action/state encoders 与 12-layer Transformer 预测 latent residual。
- future cosine loss + residual SmoothL1 + mismatched-action counterfactual ranking loss，使预测对可执行动作敏感。
- Stage 2：PaliGemma VLM 的 learnable queries 生成 latent action plan；冻结 world model 预测未来，resampler 压成 12 tokens，显式条件化 flow-matching action expert。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| RoboTwin 2.0，2,500 clean + 25,000 randomized demos，50 tasks | clean / randomized / average success | 91.46% / 91.48% / 91.47% | π0.5 81.12% / 79.64% / 80.38% | +10.34/+11.84/+11.09pp | PDF p.6 Table 1(b)。 |
| LIBERO-Plus / LIBERO-Pro / LIBERO-Para zero-shot OOD | success rate | 88.0% / 61.4% / 75.0% | π0.5 84.5% / 53.0% / 71.4% | +3.5/+8.4/+3.6pp | PDF p.7 Table 2 与邻近正文；LIBERO-Para 数值来自正文。 |
| AgileX Piper 真机三任务，每任务 200 demos、20 trials | average success rate | 73.3% | π0.5 38.3%；best other baseline LaWAM 43.3% | +35.0pp vs π0.5；+30.0pp vs LaWAM | PDF p.7 Table 3；Book/USB/Keyboard 为 85/65/70%。 |
| 真机服务端 inference | mean latency | 305.9 ms | π0.5 287.1 ms；ImageWAM 582.6 ms | +18.8 ms vs π0.5；比 ImageWAM 低 47.5% | PDF p.15 Table 11；不同模型大小与 action chunk 不完全一致。 |
