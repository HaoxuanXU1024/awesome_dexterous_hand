## 1. Splat2Act: From Captured Scenes to Personalized VLA Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2610.13945) · [PDF](https://arxiv.org/pdf/2610.13945)
- **发布日期：** 2026-10-09（近 7 天补充；超出严格窗口 5 天）
- **作者：** Xiaomeng Ye, Krishna Jaganathan, Gyubeum Lim, Gunjan Chhablani, Muhammad Zubair Irshad, Zsolt Kira
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** manipulation, sim_to_real, vla
- **灵巧手相关：** 否
- **一句话概括：** Splat2Act 用手机扫描构建 building-scale 3DGS 数字孪生，自动发现可达 receptacle、由仿真 oracle 生成示范，再以两阶段 SFT 把 π0.5 个性化到用户场景与物体。
- **核心 insight：** 个性化 VLA 的关键不只是识别用户物体，而是把目标场景的外观、可达 receptacle 和操作分布一起纳入训练；同场景 broad adaptation 再做 object personalization 明显优于直接微调。

### 方法要点

- 用 iPhone/Polycam 捕获 RGB-D，DN-Splatter 重建 3DGS，SuGaR 提取碰撞 mesh；用 SAM3D 从单图生成用户物体资产。
- 从 mesh 自动检测水平 receptacle，结合 Habitat navmesh、0.70 m reach radius、物体落稳与抓取可行性筛选任务；Isaac Sim privileged oracle 在 64 个并行环境中规划、重试并仅记录成功轨迹。
- Stage 1 用 Office1k 或 Multi1k 做广域 embodiment/场景适配，Stage 2 用部署场景内用户物体示范做个性化；完整微调 π0.5 的 PaliGemma language backbone 与 action expert，冻结 SigLIP image encoder。

## 2. RARA: Robust Policy Fine-Tuning through Retrieval-Anchored Representation Alignment for Robotic Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2610.13578) · [PDF](https://arxiv.org/pdf/2610.13578)
- **发布日期：** 2026-10-09（近 7 天补充；超出严格窗口 5 天）
- **作者：** Xuhui Kang, Sung-Wook Lee, Yan Zhuang, Tianle Zhong, Yen-Ling Kuo
- **机构/单位：** University of Virginia
- **领域标签：** manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** RARA 从预训练库检索任务语义相近且动作阶段匹配的示范，先对齐 target representation，再在 fine-tuning 时锚定 retrieved representations，以减轻小数据适配造成的 OOD 表征漂移。
- **核心 insight：** 稳健微调不应把所有参数或 target features 一律拉回预训练状态，而应只用与目标技能相关的 source demonstrations 作为锚点，让 target 学新任务的同时保留可迁移结构。

### 方法要点

- 先用 frozen CLIP instruction embeddings 取预训练 demonstrations 的 top-K，再用 action-chunk DTW 为每个 target frame 找同技能、同运动阶段的 positives 与异阶段 negatives。
- Stage 1 只更新 anchored layer 与两层 projector，以 multi-positive contrastive loss 对齐 target/retrieved features，同时用 anchor loss 约束 retrieved frames 相对 frozen pretrained policy 的漂移。
- Stage 2 按原 recipe 做 behavior cloning，并继续施加 retrieved-only anchor loss；projector 丢弃，推理时不增加模块。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| RoboTwin 四任务，Diffusion Policy，50 target demos/task | task-average success rate（ID / OOD） | RARA 76.0±1.0% / 58.3±1.2% | FT 67.4±1.4% / 47.3±2.4% | +8.6 / +11.0 个百分点 | PDF p.8 Table 2；核对 RoboTwin Task average 的 ID/OOD 列 |
| RoboCasa 五任务，DROID-pretrained GR00T N1.7，100 target demos/task | task-average success rate（ID / OOD） | RARA 74.0±1.4% / 55.5±4.8% | FT 69.2±2.5% / 44.3±2.0% | +4.8 / +11.2 个百分点 | PDF p.8 Table 2；核对 RoboCasa Task average 的 ID/OOD 列 |
| RoboTwin component ablation，四任务平均 | success rate（ID / OOD） | full RARA 76.0±1.0% / 58.3±1.2% | Stage 2 only 73.0±3.2% / 46.2±4.1%；Stage 1 only 66.6±2.2% / 43.2±1.3% | full 相对 Stage 2 only：+3.0 / +12.1pp | PDF p.9 Table 3；核对 RoboTwin avg. ID/OOD 与 ablation 行 |

## 3. Grounded-Dreamer: Robot Learning from World Model Synthetic Data with Physical Grounding

- **来源：** [arXiv](https://arxiv.org/abs/2610.13164) · [PDF](https://arxiv.org/pdf/2610.13164)
- **发布日期：** 2026-10-09（近 7 天补充；超出严格窗口 5 天）
- **作者：** Feng Jiang, Shu Chen, Yuanfei Wang, Yuan Li, Zhenhao Shen, Jiaqi Liang, Yang Chen, Lei Wei, Chen Xie, Ruihai Wu
- **机构/单位：** 1Peking University; 2Hong Kong University of Science and Technology (Guangzhou)
- **领域标签：** manipulation, robot_learning, world_models
- **灵巧手相关：** 否
- **一句话概括：** Grounded-Dreamer 用少量真实初始图重建仿真、自动收集 physics-grounded trajectories 来后训练 video world model 与 IDM，再把生成动作回放进仿真过滤物理幻觉。
- **核心 insight：** 视频生成模型负责真实外观，物理仿真负责动作可执行性；只有把 world-model rollout 反解为 action 后在重建场景中闭环重放，才能将视觉逼真度转成可信的 robot training data。

### 方法要点

- 用 FEEPE 标定相机、SAM3D 重建并缩放刚体/关节物体，在 Lehome/Isaac Sim 搭建 task-oriented scene；LLM agent 根据模板、任务描述与 object metadata 自动生成采集脚本。
- 每任务采 100–150 条仿真轨迹；Interaction-Aware Masking 仅保留 robot 与 interacting objects，以这些数据后训练 Cosmos-Predict 2.5 和 IDM。
- Nano Banana 2 把随机仿真物体合成到真实背景并增强光照/桌布，world model 生成视频、IDM 反推动作；在重建 simulator 中 replay，只保留满足 task success 的 verified trajectories。

## 4. Evo-World: A Lightweight Vision-Language-Action Model with Future Motion Prediction via Optical-Flow Supervision

- **来源：** [arXiv](https://arxiv.org/abs/2610.12936) · [PDF](https://arxiv.org/pdf/2610.12936)
- **发布日期：** 2026-10-09（近 7 天补充；超出严格窗口 5 天）
- **作者：** Zile Zhong, Yuxin Du, Tao Lin, Haoxiao Wang, Wei Dai, Binhua Zuo, Bo Zhao
- **机构/单位：** 1School of AI, Shanghai Jiao Tong University 2Zhejiang University; 3University of Electronic Science and Technology of China 4QuicRobot
- **领域标签：** dexterous, manipulation, robot_learning, vla
- **灵巧手相关：** 否
- **一句话概括：** Evo-World 用 optical-flow rendering 的 latent prediction 给 0.87B VLA 注入未来运动先验，并用 SIGReg 与 action-gradient detach 防止预测表征在 policy learning 中坍塌。
- **核心 insight：** 对控制有用的未来信号主要是场景运动而非静态外观；预测 optical-flow embedding 比预测 future RGB 更聚焦，同时无需部署时解码图像或运行 flow estimator。

### 方法要点

- DINOv2 编码当前指定视角，CLIP 编码 instruction，MLP 预测未来 motion representation；训练 target 是 RAFT 计算的 t→t+15 optical flow 经 RGB color wheel 渲染后的 DINOv2 embedding。
- InternViT+InternVL3-1B 提供 VLM context；把 current/predicted motion embeddings stop-gradient 后拼接，经 bounded、zero-init FiLM 调制 VL tokens，再由 flow-matching action expert 生成 action chunk。
- world loss 结合 latent prediction 与对 current/target batch 的 SIGReg；action loss 不回传 motion module，从而分离 predictive representation learning 与 control optimization。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| Meta-World MT50，四难度 tier 等权平均 | tier-averaged success rate | Evo-World 91.1% | non-predictive Evo-1 80.6%；Future RGB 84.3% | +10.5pp vs Evo-1（约 +13.0% relative）；+6.8pp vs Future RGB | PDF p.7 Table 1 与 p.8 Table 3 group A；核对四 tier 及 Tier Avg. 表头 |
| AgileX dual-arm，3 tasks，各 20 trials，NVIDIA H20 BF16 | average success；GPU memory；inference frequency | 63.3%；2.54 GB；6.16 Hz | π0 51.7%；6.69 GB；5.42 Hz | success +11.6pp；memory -62.0%；frequency +13.7% | PDF p.8 Table 2；核对 Avg SR、GPU Mem. 与 Infer. Freq. 行 |
| Meta-World component ablation，同训练预算 | tier-averaged success rate | full 91.1% | w/o SIGReg 85.8%；w/o Grad. Detach 82.2% | +5.3 / +8.9 个百分点 | PDF p.8 Table 3 group D；核对 Component ablation 与 Tier Avg. |

## 5. Dual-Stream Memory for Vision-Language-Action Policies

- **来源：** [arXiv](https://arxiv.org/abs/2610.13262) · [PDF](https://arxiv.org/pdf/2610.13262)
- **发布日期：** 2026-10-09（近 7 天补充；超出严格窗口 5 天）
- **作者：** Yang Wang, Ping Liu, Ruiyu Wang, Xuhua Chen, Lingfeng Zhang, Tao Zhang
- **机构/单位：** 1Magic-Lab Team, Magiclab Robotics Inc.; 2University of California, Los Angeles, USA
- **领域标签：** manipulation, robot_learning, vla
- **灵巧手相关：** 否
- **一句话概括：** Dual-Stream Memory 将长时操作记忆拆为执行阶段压缩与任务相关视觉证据检索两条流，在 RoboMME 和 Piper 真机上同时改善重复动作与历史线索调用。
- **核心 insight：** 长时机器人记忆不是单一压缩问题：重复动作需要紧凑的执行进度状态，遮挡与目标重识别则需要可直接访问的历史空间细节；将两者分流建模比单一记忆 token 或均匀抽帧更稳健。

### 方法要点

- 时间流以 DINOv3 全局特征和 6 层 Gated DeltaNet 压缩 stride-3 历史为单个 512 维 temporal token，并用 progress prediction 与 action-conditioned historical-feature reconstruction 预训练。
- 空间流用 frozen SigLIP patch features 与 MiniLM task query 做因果相关性打分，以固定 0.6 LSE-logit 阈值自适应保留历史帧；同一分数网格接受 temporal keyframe 与 spatial mask 监督。
- 每个保留帧把 2×2、4×4、8×8 多尺度特征线性融合为 16 个 1,024 维 token；π0.5 action expert 分别 cross-attend 两条记忆，再以可学习门控相加。
- 两阶段训练先学习 GDN 压缩器，再冻结 GDN、联合训练 retriever、multi-scale fusion 与 π0.5 policy；SigLIP 和 MiniLM 保持冻结。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| RoboMME 16 tasks；每任务 3 个 evaluation seeds（0/7/42），每 seed 50 episodes | overall mean task success rate (TSR) | 49.22% | published FrameSamp+Modul 44.51% | +4.71 个百分点 | PDF p.7 Table II；核对 suite/task 行、Overall mean 列与 Δ(pp) 表头。论文注明 baseline checkpoint aggregation 与作者实现不同。 |
| RoboMME component comparison：Counting / Permanence / Reference suites | suite mean TSR | GDN 72.17%、Retrieval 29.33%、Linear multi-scale fusion 40.83% | 对应 FrameSamp+Modul 65.22%、25.11%、36.33% | +6.94 / +4.22 / +4.50 个百分点 | PDF p.5 Table I；核对 Component/suite、Base、Addition、Δ(pp) 表头及三条 Suite mean。 |
| Piper dual-arm real robot，4 tasks，每任务 30 rollouts；所有方法使用相同 400 demonstrations | mean TSR | 62.5% | FrameSamp+Modul 37.5% | +25.0 个百分点 | PDF p.6 Table III 与 p.7 邻近正文；核对 Pick×3、Swing×2、RePick、Shell、Avg. 表头。Shell 单项反而由 53.3% 降至 40.0%。 |
