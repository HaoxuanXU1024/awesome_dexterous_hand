## 1. AtomicRL: Atomic Reinforcement Learning for Long-Horizon Robotic Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2610.30097) · [PDF](https://arxiv.org/pdf/2610.30097)
- **发布日期：** 2026-10-21（近 7 天补充；超出严格窗口 3 天）
- **作者：** Likui Zhang, Zhe Zhu, Zhihao Zhan, Yibo Bai, Hanlin Wang, Dongwei Li, Bin Wang, Tianle Zhang, Xiaodan Liang, Liang Lin
- **机构/单位：** 1Sun Yat-sen University 2The Hong Kong Polytechnic University 3JD Explore Academy
- **领域标签：** manipulation, robot_learning, sim_to_real, vla
- **灵巧手相关：** 否
- **一句话概括：** AtomicRL 把长时程任务拆成 atomic subtasks，用 SAPO 阻断失败子任务对已完成前缀的错误 credit propagation，再用 BATE 把采样与探索预算集中到尚未掌握的瓶颈子任务。
- **核心 insight：** 稀疏终局奖励的核心问题不只是奖励少，而是标准 GAE 会把后段失败的 TD residual 反向污染此前已正确完成的步骤；语义边界因此既可作为 credit-assignment gate，也可作为针对性探索的统计单元。

### 方法要点

- PCC（Progress-Completion Critic）从最近 L 个 observation-action pairs 预测子任务进度与完成边界，并提供 progress-based shaping reward；其训练标注由 VLM 生成后人工修正。
- SAPO 保留 one-step TD residual 与 value bootstrap，仅在跨越语义边界时用 outcome-aware soft gate 调制 GAE trace：成功子任务间正常传播，失败子任务的 residual 向已完成前缀传播时衰减。
- BATE 用每个 atomic subtask 完成率的 EMA 表示 mastery，同时提高包含低 mastery 子任务的整任务采样权重，并在该子任务局部增加 entropy exploration。
- Real2Sim2Real 从一条 LeRobot 实机示范、物体多视图与材质信息构建 MuJoCo 交互环境，在 RLinf 中并行训练后通过相同控制接口部署到 AgiBot G1。

## 2. Vision-Language-Delta-Action: Learning Compact Deltas as Actionable Transition Interfaces for Robotic Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2610.25874) · [PDF](https://arxiv.org/pdf/2610.25874) · [Hugging Face](https://huggingface.co/papers/2610.25874)
- **发布日期：** 2026-10-19（近 7 天补充；超出严格窗口 5 天）
- **作者：** Lingsen Zhang, Wei Li, Jie He, Henghua Zhang, Kai Mo, Shiyong Li, Yanpeng Wang, Rui Shao
- **机构/单位：** 1Harbin Institute of Technology, Shenzhen 2Baidu, Inc. 3Shenzhen Loop Area Institute
- **领域标签：** embodied_ai, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** VLDA 不预测完整未来画面，而学习稀疏、可执行的 latent Delta，并用它为 action flow 提供噪声偏置与 prefix conditioning，在 LIBERO-Plus、RoboTwin 2.0 和双臂实机长时程任务上提升泛化。
- **核心 insight：** 机器人动作真正需要的是任务相关的“哪里、怎样改变”，而非静态背景占多数的完整 future state；用 local transition selection 保留交互变化、global anchor 保持总体趋势，再对齐 action manifold，可把未来信息变成直接可消费的 action prior。

### 方法要点

- World Expert 从当前 primary-view 与 future-view 的 V-JEPA 2 features 构造 dense difference，LT-Filter 选 top-K 高变化 tokens（K=64）并降维成 Delta target。
- GT-Anchor 对未来 feature 做粗粒度 pooling，为 Delta 提供 scene-level transition consistency，避免只关注局部变化。
- DDAR 通过 Delta-to-Action Manifold Grounding 将 Delta tokens 与当前 action chunk 的正样本对齐、与同轨迹其他时段负样本做 InfoNCE。
- Delta-Seeded Action Flow 把 mean-pooled Delta 同时变为 action-noise bias 与 prefix token；采用 transition pretraining 后 joint optimization 的两阶段训练，推理无需 future image。

## 3. SP-HLM: Sparse-Pose-Driven Motion Generation and Whole-Body Control for Humanoid Loco-Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2610.30044) · [PDF](https://arxiv.org/pdf/2610.30044)
- **发布日期：** 2026-10-21（近 7 天补充；超出严格窗口 3 天）
- **作者：** Zhaohui Yang, Quanbao Lin, Chengqi Shi, Zhenglang Weng, Jicheng Lin, Boyu Chen, Tengjie Zhu, Guanzhu Ren, Jiahao Xu, Yang Feng, Xiaokang Yang, Yao Mu
- **机构/单位：** 1Shanghai Jiao Tong University 2Moore Threads; 3The University of Hong Kong; ∗Equal contribution. †Interns at Shanghai Jiao Tong University.
- **领域标签：** humanoid, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** SP-HLM 用 pelvis、双 wrist、双 ankle 五个显式 sparse poses 表达空间意图，再用 latent whole-body motion prior 补足协调信息，把 VLA、实时 motion generation 与全身 tracking 接成 humanoid loco-manipulation 系统。
- **核心 insight：** 高层策略无需在 joint-space、task-space 与 token-space 三者中二选一：任务关键几何可以显式给出，而难以手工指定的全身协调可以隐式编码，二者交给统一 tracker 融合。

### 方法要点

- SP-VLA 从 GR00T N1.7 初始化并仅微调 flow-matching action head，预测 40-step 的五点 world-frame poses 与双手 finger-joint targets；RTC prefix conditioning 支持异步 action-chunk 推理。
- SP-MGM 压缩 pretrained KIMODO diffusion generator，通过 Stage I teacher+GT offline distillation 与 Stage II student-visited-state rollout-aware distillation，在稀疏约束下恢复全身轨迹。
- 预训练 motion VAE 将 yaw-invariant 10-frame 全身 motion window 编为 latent prior；SP-GMT 用 PPO 融合该 latent、pelvis-frame sparse targets、proprioception 与 previous action。
- 部署时 SP-VLA→SP-MGM→motion encoder→SP-GMT 串联，手指目标直接交给 hand PD controller；TensorRT 下 VLA/MGM 分别约 25/10 Hz。

## 4. From VLM Planners to Robotic Agents: Self-Evolving Harnesses for History-Dependent Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2610.29560) · [PDF](https://arxiv.org/pdf/2610.29560) · [Hugging Face](https://huggingface.co/papers/2610.29560)
- **发布日期：** 2026-10-21（近 7 天补充；超出严格窗口 3 天）
- **作者：** Tingwen Du, Haoyu Guo, Hanxue Zhang, Xuanxu Wang, Junting Dong, Chao Gao, Mingfei Han, Tao Lu, Mulin Yu, Chunhua Shen, Xiaojun Chang, Zhihui Li
- **机构/单位：** 1University of Science and Technology of China; 2Shanghai Artificial Intelligence Laboratory 3Shanghai Jiao Tong University; 4Mohamed bin Zayed University of Artificial Intelligence 5Zhejiang University
- **领域标签：** embodied_ai, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** SERA 在冻结 VLA executor 外包一层可编辑 agent harness，持续维护任务进度与执行反馈，并用 development rollouts 自动诊断、修订、验证 planning guidance、assessment criteria 和 control rules。
- **核心 insight：** 长时程非 Markov 操控需要的不是单纯堆历史帧，而是把历史压缩成可更新的 task context；同一份外部 harness 既能负责 episode 内状态维护，也能作为 episode 间从失败经验中演化的可审计对象。

### 方法要点

- 初始化时从 instruction 与 initial context 生成固定 episode guidance；运行时 context 保存 task progress、decision-relevant facts、execution outcomes、uncertainty 与 stagnation control state。
- 每轮高层 VLM 联合观察 guidance、近期前/腕视图、当前 context、上一 command 与候选 action catalog，同时产出更新后的 context 和要交给固定 VLA executor 的 command。
- self-evolution 的 analysis/revision agents 从 observation-command-context-outcome traces 定位首个偏离点，并提出对 guidance、criteria 或 registered control rules 的结构化修订。
- verifier 在开发 episodes 上比较 base/candidate 的 repaired failures 与 regressed successes；选中的 harness 在 held-out test 前冻结，测试结果不回流修订。

## 5. Agentic World Action Models

- **来源：** [arXiv](https://arxiv.org/abs/2610.30136) · [PDF](https://arxiv.org/pdf/2610.30136) · [Hugging Face](https://huggingface.co/papers/2610.30136)
- **发布日期：** 2026-10-21（近 7 天补充；超出严格窗口 3 天）
- **作者：** Zhuoyang Liu, Dantong Niu, Botong Zhang, Boning Shao, Jing Wang, Ruijie Zheng, Yuvan Sharma, Runyu Lu, Jiaming Liu, Renrui Zhang, Roei Herzig, Yutong Bai et al.
- **机构/单位：** 1 UC Berkeley 2 NVIDIA 3 University of Pennsylvania; Primitive APIs
- **领域标签：** dexterous, manipulation, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** AW-0 在 Mixture-of-Transformers 中联合去噪 code、future video 与 action 三条流，让可复用 skill program 同时充当 world-action prediction 的语义计划，并在通过 gate 时直接接管一部分控制步骤。
- **核心 insight：** world action model 的视觉动力学与 agentic code 的组合性互补：code 把长任务结构化并复用 skill，video/action 把计划锚定到物理变化；把三者放在同一去噪过程里，比串行先生成文本再预测动作更快且误差更少。

### 方法要点

- 三 expert MoT 分别处理 masked-token code diffusion、video latent flow matching 与 action flow matching；blockwise causal 顺序 C→V→A，使 program 同时指导未来视觉与动作。
- 自动标注 pipeline 用 Gemini 3.1 Pro 写 subtask programs、Claude Opus 4.8 协调并提炼重复 routine，冻结 23 个 YAM 与 27 个 egocentric-human skills 后为全部 demonstrations 对齐 program slices。
- code expert 读取当前多视图、instruction、robot state 与历史 program-slice memory；默认 code 只作为 action expert 的 plan condition，不直接执行。
- hybrid mode 对 code slice 做 stage、dependency、syntax/whitelist/vacuity gates；通过时调用 perception/control primitives，否则执行同一次 forward pass 的 action chunk。

### 实验与结果
