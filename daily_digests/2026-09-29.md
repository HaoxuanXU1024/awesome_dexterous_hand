## 1. Towards VLA-Dreamer: Refining VLA Behavior Using World Models

- **来源：** [arXiv](https://arxiv.org/abs/2609.31313) · [PDF](https://arxiv.org/pdf/2609.31313)
- **发布日期：** 2026-09-25（近 7 天补充；超出严格窗口 4 天）
- **作者：** Parsa Mastouri Kashani, Jan-Gerrit Habekost, Stefan Wermter
- **机构/单位：** Knowledge Technology, Dept. of Informatics, University of Hamburg, Germany
- **领域标签：** foundation_models, robot_learning, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** VLA-Dreamer 提议直接在 VLA 冻结视觉编码器的 embedding space 中训练 action-conditioned world model，再让已适配机器人本体的 VLA 在该模型内用 RL 做细粒度动作修正。
- **核心 insight：** 这篇 concept paper 的核心不是像素级预测，而是把同一份 language-aligned visual embedding 同时用作策略输入、未来预测目标和 goal-distance reward，从而检验 VLA 视觉表征是否已包含可预测的物理状态。

### 方法要点

- 先在 NICOL 的语言指令、相机帧与 proprioception 遥操作数据上微调 π0-FAST 或 OpenVLA，并冻结视觉编码器以保持 world-model target 一致。
- world model 输入近期视觉 embeddings、当前 proprioception 与 action，预测下一时刻视觉 embedding 和 proprioception；随机动作与专家/半专家数据混合以扩大动力学覆盖。
- 用 segmentation、depth 与 image-decoder probes 测 embedding 的语义/几何保真度，再以当前和目标 embedding 的负 MSE 为 dense reward，在短 imagination horizon 内用 PPO 修正 VLA。

## 2. VLaRL: Augmenting Vision-Language-Action Models with Simulation-Trained Latent-Conditioned Residual RL

- **来源：** [arXiv](https://arxiv.org/abs/2609.30868) · [PDF](https://arxiv.org/pdf/2609.30868)
- **发布日期：** 2026-09-25（近 7 天补充；超出严格窗口 4 天）
- **作者：** Namiko Saito, Kinam Kim, Heecheol Kim, Katsushi Ikeuchi, Yasuyuki Matsushita
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** manipulation, sim_to_real, vla
- **灵巧手相关：** 否
- **一句话概括：** VLaRL 把冻结 VLA 的 vision-language latent 当作 sim-to-real 接口，通过 latent mapper 对齐仿真与真实分布，再在仿真中训练 residual RL 并零适配部署到 Franka 真机。
- **核心 insight：** 与其让仿真像素逼真，不如直接对齐 VLA 内部真正用于决策的 latent；残差策略在训练时消费映射后的仿真 latent，在部署时直接消费真实 latent，因此 mapper 不进入真实控制环。

### 方法要点

- 冻结 Flower 或 GR00T N1.7，保留 nominal 7-D action；对 VLM token mean pooling 后，与 proprioception、Cartesian force 和 nominal action 一起输入 residual policy。
- 用近似对应的 sim-real trajectories 和 Sinkhorn divergence 训练轻量 latent mapper，使仿真 latent 靠近真实分布。
- 在 MuJoCo 中以 TD3 训练 bounded residual action（scale 0.10），critic 可见 privileged state；部署时 VLA 与 residual policy 全冻结，不做 real-world RL 或 online adaptation。

### 实验与结果

|---|---|---|---|---|---|
| Franka Research 3，4 个 contact-rich tasks × Flower/GR00T N1.7；每个真实条件 40 trials | real-robot success rate | Flower: button 100.0%、push 50.0%、stack 70.0%、drawer 87.5%；GR00T: 95.0%、52.5%、45.0%、55.0% | 冻结 VLA 分别为 Flower 67.5/22.5/65.0/65.0%，GR00T 87.5/45.0/17.5/45.0% | 8 个 task-backbone 组合全部提升；最大可核验增益为 GR00T cup stacking +27.5 点 | PDF p.6 Fig. 5；核对任务、backbone、40 trials 和实心柱图例 |
| Flower mapper/latent controlled ablation，真实机器人每任务 40 trials | success rate | 完整 VLaRL 在 push/stack 为 50.0%/70.0% | w/o Mapper 在两项均为 0.0%；w/o VLM latent 的 button/push 为 70.0%/20.0% | mapper 对 push/stack 分别 +50/+70 点；VLM latent 对 button/push +30/+30 点 | PDF p.7 Fig. 7 与 Sec. V-B；核对仿真/真实纹理图例 |

## 3. Federated Subspace Guided Vision-Language-Action Policy Distillation for Non-IID Multi-Robot Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2609.32239) · [PDF](https://arxiv.org/pdf/2609.32239v1)
- **发布日期：** 2026-09-26（近 7 天补充；超出严格窗口 3 天）
- **作者：** Biprodip Pal, Kaushik Roy, Yanming Zhu, Brendan Tidd, Alan Wee-Chung Liew, Peyman Moghadam
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** FedDRMan 在非 IID 多机器人模仿学习中同时约束 multimodal representation/action drift，并按 client update compatibility 分簇后做 spectral rebalancing，避免异质任务更新互相抵消。
- **核心 insight：** 非 IID federation 的破坏来自两层：本地适配让表征和动作分布漂移，跨任务 client updates 又会在平均时抵消；因此需要 local distillation 与 server-side compatible aggregation 两端共同处理。

### 方法要点

- 每轮把 server model 冻结为 teacher，本地以 BC、低秩 multimodal subspace cross-projection loss 和 action-distribution distillation 联合训练。
- 以 client 相对共同 initialization 的累积 update cosine similarity 做 compatibility-aware grouping，每个 cluster 保持 persistent server model。
- 完整模型在 cluster 内加权聚合后，对合格二维权重块执行 spectral rebalancing，抬升被平均削弱的较小 singular directions，且不增加 client-server payload。

## 4. MemBodied: Recurrent Associative Memory for Vision-Language-Action Models

- **来源：** [arXiv](https://arxiv.org/abs/2609.28256) · [PDF](https://arxiv.org/pdf/2609.28256) · [Hugging Face](https://huggingface.co/papers/2609.28256)
- **发布日期：** 2026-09-23（近 7 天补充；超出严格窗口 6 天）
- **作者：** Tej Deep Pala, Navonil Majumder, Bryce Goh, Raphael Yee, Jianfei Yang, Liming Chen, Soujanya Poria
- **机构/单位：** 1Nanyang Technological University 2Griffin Labs 3 ´Ecole Centrale de Lyon; /githubCode:https://github.com/declare-lab/MemBodied; /gl⌢beProject Website:https://declare-lab.github.io/MemBodied
- **领域标签：** embodied_ai, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** MemBodied 以固定大小的逐层 associative matrices 记录 action→视觉后果，并用独立 initial-scene anchor 保存初始布局，从而让 VLA 获得不随 episode 增长的记忆。
- **核心 insight：** 交互历史和初始场景承担不同记忆职责：delta-rule state 适合持续更新 episode 进展，固定 anchor 则防止早期细节被反复写入覆盖。

### 方法要点

- 每个 action-network layer 维护 128×128 associative state；当前 state token 生成 query 读取 memory，结果注入专用 memory token。
- 执行 action chunk 后，将该动作与下一帧视觉后果组成 value，以 retention/write gates 的 delta rule 因果写回 memory。
- 首帧各相机 16×16 patch 压缩为 4×4 anchor；当前 state 通过 rank-64 cross-attention 选择性检索，sequence training 让后续 action loss 反传到早期写入。

| NativeMEM 同一评测配置 | inference latency / peak GPU memory / added parameters | MemBodied: 129ms / 18.6GiB / 40M | NativeMEM: 1594ms / 20.6GiB / 415M | 延迟 -91.9%，峰值显存 -9.5%，新增参数约 1/10 | PDF p.7-8 Fig. 2(b) 与 Sec. 5.2 正文 |
