## 1. SAVLA: Symmetry-Aware Vision-Language-Action Models for Robotic Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2609.16641) · [PDF](https://arxiv.org/pdf/2609.16641)
- **发布日期：** 2026-09-15（近 7 天补充；超出严格窗口 2 天）
- **作者：** Junle Li, Weixian Waylon Li, Fuxiang Wu, Fusheng Hao, Fengxiang He
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** manipulation, robot_learning, vla
- **灵巧手相关：** 否
- **一句话概括：** SAVLA 在冻结的 GR00T N1.5 视觉语言骨干之外加入 SO(3) typed equivariant flow-matching action head 与重力轴 canonicalizer，使 VLA 在场景旋转和低数据条件下保持更强鲁棒性。
- **核心 insight：** 关键不是再做更多旋转增强，而是把标量/向量通道的变换类型写进动作头，并用同一个角度估计同时规范化斜视 RGB 与旋转几何 reference points；消融表明 canonicalization 或 equivariant head 单独使用都远不如二者组合。

### 方法要点

- 把 state/action 拆为 invariant scalar track 与 equivariant vector track；normalization、attention、FFN 和 cross-track interaction 均保持旋转变换律。
- 对 ViT patch center 反投影得到 tabletop reference points，作为与 VLM scalar tokens 对齐的 type-1 geometric conditions。
- 三层 CNN 在 8 个候选角度上估计场景旋转，通过 tabletop homography 把第三人称斜视图 warp 到 canonical view；同一角度用于旋转几何条件。
- 从各向同性高斯 action chunk 出发，以 4 步 explicit Euler flow integration 生成 16 步动作；预训练 VLM 全冻结。

## 2. SWIM: Vision-Language-Grounded Soft Whole-Body Interactive Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2609.17035) · [PDF](https://arxiv.org/pdf/2609.17035)
- **发布日期：** 2026-09-15（近 7 天补充；超出严格窗口 2 天）
- **作者：** Tingcong Liu, Aye Phyu Phyu Aung, Junjie Xiong, Siyi Ma, Bo An, Ke Wu, Senthilnath Jayavelu
- **机构/单位：** 1Nanyang Technological University, Singapore; 2National University of Singapore, Singapore; 3Mohamed bin Zayed University of Artificial Intelligence, Abu Dhabi, United Arab Emirates; 4Institute of Advanced Intelligence and Computing, A*STAR, Singapore
- **领域标签：** embodied_ai, foundation_models, humanoid, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** SWIM 让软体连续机器人从初始 RGB 和语言指令生成完整 tendon-command 序列，并把 VLA 推理放进 MuJoCo virtual rollout，再依靠物理柔顺性开环执行。
- **核心 insight：** 论文把软体机器人的两个难题拆开：训练时用 Visual Soft Proprioception 强迫表示保留整条柔性本体几何，用 diffusion 拟合一对多的 tendon sequence；部署时避开约 700 ms 在线 VLA 延迟，以虚拟闭环构造整段命令、真实机器人开环执行。

### 方法要点

- OpenVLA-OFT backbone 接收 top-down RGB、language 和当前两路 tendon length，diffusion head 预测 H=15 的 torque-command chunk。
- 训练期 VSP head 回归沿 backbone 排列的 4 个 image-plane anchors，与 diffusion noise loss 联合优化；部署时移除 VSP head。
- 每次 virtual rollout 执行 chunk 前 K=8 条命令，用更新后的模拟 RGB/tendon state 继续查询，直至拼成完整序列。
- 真实执行不再查询 VLA 或视觉反馈，由 SpiRob 的 intrinsic compliance 吸收局部接触偏差。

## 3. FluxVLA Engine: A One-Stop VLA Engineering Platform for Embodied Intelligence

- **来源：** [arXiv](https://arxiv.org/abs/2609.17210) · [PDF](https://arxiv.org/pdf/2609.17210)
- **发布日期：** 2026-09-15（近 7 天补充；超出严格窗口 2 天）
- **作者：** Yinhao Li, Weixin Mao, Zihan Lan, Jikun Rong, Qirui Hu, Yiming Zhang, Weipeng Deng, Bowen Shen, Minzhao Zhu, Yiming Mao, Yan Yang, Chenguang Cui et al.
- **机构/单位：** 1LimX Dynamics 2Nankai University 3The University of Hong Kong; 4University of Electronic Science and Technology of China5Beijing Institute of Technology; 6Xidian University 7Zhejiang University 8Xi’an Jiaotong University
- **领域标签：** embodied_ai, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** FluxVLA Engine 不是新 VLA 模型，而是一套把异构 dataset、policy、训练、仿真评测、加速推理、RTC、轨迹后处理和真实机器人 operator 串成可重建工作流的开源平台。
- **核心 insight：** 它把可复现性的关键放在稳定 contracts：LeRobot/Parquet 与 ordered transforms 定义输入语义，registry/native wrapper 定义模型边界，runner/operator 分离模型时序与硬件 I/O，完整权重、resolved config、normalization statistics 一起打包；但论文主动区分 project-reported、companion-study 与自行审计证据，避免把集成覆盖误当成算法提升。

- 以 hierarchical Python config 和 type-keyed registry 描述 data-model-training-eval-deployment 全生命周期，同时保留 π0、WAM 等原生耦合架构。
- 统一 LeRobot-compatible Parquet、episode-aware temporal sampling、canonical sample dictionary、normalization 与 train/inference transforms。
- runner 负责 distributed training、checkpoint、action chunk scheduling、RTC 与 post-processing；operator 仅负责 simulator/robot sensor-command I/O。
- 提供 Triton/CUDA Graph/custom CUDA 加速、remote GPU serving、Training-time/Test-time RTC、joint MPC/Ruckig，以及 ALOHA/Oli 等机器人接口。

## 4. TEMPO: Learning Temporal Context for Dynamic Robot Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2609.16864) · [PDF](https://arxiv.org/pdf/2609.16864)
- **发布日期：** 2026-09-15（近 7 天补充；超出严格窗口 2 天）
- **作者：** Zhenyang Feng, Jimin Heo, Erik B. Sudderth, Unnat Jain
- **机构/单位：** University of California, Irvine
- **领域标签：** foundation_models, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** TEMPO 用 frozen video encoder 的 motion token 加上压缩后的 proprioceptive action history，为单帧 VLA 补上动态目标速度与任务阶段信息。
- **核心 insight：** 动态操控失败不只来自 inference latency：motion ambiguity 要看最近视觉，state aliasing 要看机器人刚做过什么；TEMPO_MOT 与 TEMPO_ACT 分别解决这两类不可从当前帧恢复的信息，而且只增加 2M 参数和约 1.5 ms policy-side overhead。

### 方法要点

- TEMPO_MOT 用当前 patch 作为 query，对 rolling cache 中 W−1 帧特征做 cross-attention；默认 frozen SAM 2.1-Tiny 在后台线程以 sensor rate 更新。
- TEMPO_ACT 把最近 300 条 proprioceptive commands 分成 K=10 个 bucket，每 bucket 均值形成固定长度 phase history。
- 两种 token 投影后加入 VLM prefix；action history 还通过 zero-initialized AdaRMS residual 直接调制 action expert。
- 以 VLASH async pipeline 为主干，flow-matching loss 不变；motion encoder 与 VLA control loop 并行。

## 5. sensVLA: Spatially-Grounded Vision-Language-Action Model for Autonomous Wheel Loader

- **来源：** [arXiv](https://arxiv.org/abs/2609.17021) · [PDF](https://arxiv.org/pdf/2609.17021)
- **发布日期：** 2026-09-15（近 7 天补充；超出严格窗口 2 天）
- **作者：** Gopi Krishna Erabati, Bjarne Johannsen, Angus Stewart, Vardeep Singh Sandhu
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** sensVLA 将冻结 PointPillars 的 lidar BEV tokens 直接 cross-attend 到 flow-matching action expert，与 Qwen3-VL 的 RGB/text 语义分流，为轮式装载机提供 metric spatial grounding。
- **核心 insight：** BEV 不必塞进容量有限的 LoRA VLM：让 VLM 保留语言-视觉语义，把可度量几何直接送到动作决策层，在 loading 这种 pile/corridor geometry 关键的 slice 上收益最大，并在 camera loss 时提供不对称冗余。

### 方法要点

- front/rear RGB 与 text 经 frozen ViT、截断到前 14 blocks 的 Qwen3-VL-2B；当前 proprioception 作为额外 token。
- 10-step state history 经 temporal encoder 压缩；前后 lidar 在 0.5 s 内累积，经 frozen PointPillars 得到 multi-scale BEV tokens。
- action expert 以 heterogeneous cross-attention 分层读取 VLM context、BEV 和两者融合，预测 10×6 action chunk。
- 使用 Beta(2,5) flow time、per-component weighted velocity MSE 与 10-step midpoint ODE solver。

| loading validation slice | v_x RMSE / displacement d_x RMSE ↓ | 0.717 m/s / 8.40 cm | 0.996 m/s / 9.27 cm | −28.0% / −9.4% | PDF Table I 与紧邻正文，p.4；表格只显示 dx+dy aggregate，dx 数字来自相邻正文 |
