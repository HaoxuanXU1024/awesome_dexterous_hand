## 1. GaussianDream++: Efficient 3D Gaussian World Modeling for Robotic Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2608.25659) · [PDF](https://arxiv.org/pdf/2608.25659)
- **发布日期：** 2026-08-26（近 7 天补充；超出严格窗口 5 天）

- **领域标签：** foundation_models, manipulation, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** GaussianDream++ 将当前/未来 3D Gaussian 世界监督压缩进 20 个 world tokens，推理时移除渲染与 rollout，在 LIBERO、LIBERO-Plus 和真机上提升 VLA 操作鲁棒性。
- **核心 insight：** 把 GaussianDream 的密集几何与未来预测监督变成 policy-native tokens：World State Tokens 表示当前结构，World Prediction Tokens 表示短期演化；训练期 World Representation Head 做 Gaussian 重建，部署期只保留轻量 token 前缀。

### 方法要点

- 在 PaliGemma VLA 前缀插入 20 个 World State/Prediction Tokens，并与视觉、语言 token 联合上下文化。

- 推理时移除 World Representation Head、renderer、VGGT/TGE pathway 和 future rollout，只将 tokens 送入 Action Expert。

## 6. RA-VLA: Retrieval-Augmented VLA for Test-Time Adaptation

- 将检索片段作为 in-context guidance 输入冻结 VLA，不做梯度更新。

| LIBERO-Goal buffer/retrieval ablation | average success rate | N=1/2/3/4: 48.2/51.8/53.2/55.2% | 不同 buffer size N | 随 N 增长 +7.0 pp（1→4） | PDF p.8, Table 4；表头为 buffer size N 与 retrieval size K。 |
