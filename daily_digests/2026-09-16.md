## 1. IMPACT-VLA: Interaction-aware Multimodal Propagation Attribution via Counterfactual Trajectories for Vision-Language-Action Policies

- **来源：** [arXiv](https://arxiv.org/abs/2609.15005) · [PDF](https://arxiv.org/pdf/2609.15005)
- **发布日期：** 2026-09-14（近 7 天补充；超出严格窗口 2 天）
- **作者：** Jinwoong Kim, Sangjin Park
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** foundation_models, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** IMPACT-VLA 用 action-transition-aligned phase-modality blocks 和闭环反事实重执行，解释 VLA 在何时依赖何种模态及早晚阶段信息如何非加性耦合。
- **核心 insight：** 对机器人策略做解释不能只看一次 forward 的 action sensitivity：替换早期输入会改变之后的环境状态与观测，所以贡献必须以最终任务成功为目标、在闭环中重跑；轨迹重新汇合与功能恢复也必须分开衡量。

### 方法要点

- 从成功参考 rollout 的实际 action transitions 做 CUSUM segmentation，再把边界对齐到 VLA query/action-chunk boundary。
- 将 phase×modality 作为 Shapley player；对 coalition 中被移除的 block 进行 mean/gray/blur/noise replacement，并从相同初态闭环重执行到终止。
- 用 128 个 sampled permutations 估计 block Shapley contribution，并计算跨阶段 Shapley-Taylor interaction。
- 用 end-effector trajectory deviation 区分 Behavioral Recovery，用最终 task success 区分 Functional Recovery。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| OpenVLA-OFT，30 个 LIBERO tasks | 出现相邻 phase dominant-modality transition 的 task 比例 | 25/30（83.3%） | 92 次 dominant-set change 中 37 次（40.2%）前后集合完全不重叠 | 描述性统计；不作方法提升声明 | PDF Fig.3 邻近正文，p.6 |
| closed-loop deletion / insertion faithfulness，30 LIBERO tasks | pAUC ↑ | IMPACT-VLA：Deletion 0.810 [0.746,0.861]；Insertion 0.104 [0.050,0.163] | Static Action Perturbation：0.670 [0.548,0.777] / 0.030 [0.002,0.062] | +0.140 deletion；+0.074 insertion | PDF Table III，p.6 |
| temporal structure ablation，top-modality removal | closed-loop success decrease ↑ | Action-transition-aligned phases 0.948 [0.883,0.993] | Uniform query-aligned 0.931；Modality-only Shapley 0.915 | +0.017 相对 uniform；+0.033 相对 modality-only | PDF Table IV，p.7 |
| 1,046 个 negative cross-phase pairs，30 tasks | later-block marginal gain ↑ | 早期 block 被替换后 0.082 [0.072,0.093] | 早期 block 保留时 0.025 [0.017,0.033] | +0.057；约 3.3× | PDF Sec.4.5，p.7 |

## 2. Show-Harness: Just a VLM Agent Can Play Robots

- **来源：** [arXiv](https://arxiv.org/abs/2609.10522) · [PDF](https://arxiv.org/pdf/2609.10522) · [Hugging Face](https://huggingface.co/papers/2609.10522)
- **发布日期：** 2026-09-09（近 7 天补充；超出严格窗口 7 天）
- **作者：** Yanzhe Chen, Zechen Bai, Zhijun Cao, Wenzheng Zeng, Kevin Qinghong Lin, Yiqi Lin, Guoqiang Liang, Kevin Yuchen Ma, Qiming Huang, Mike Zheng Shou
- **机构/单位：** Show Lab, National University of Singapore
- **领域标签：** embodied_ai, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** Show-Harness 把机器人控制改写为 VLM 可理解的离散 semantic action units，再由 embodiment interpreter 确定性映射到小步 Cartesian 动作。
- **核心 insight：** 有效接口既不能把连续控制全部塞给 VLM，也不能把任务责任交给黑箱 skill；它需要可观察、可组合、粒度细且有明确物理约定，让 VLM 每步作决定并用执行反馈纠错。

### 方法要点

- 动作集合含 MV_*、ROTATE_*、GRASP/RELEASE/DONE；interpreter 维护 6-DoF setpoint、坐标变换与安全投影。
- perceive-reason-act harness 组合 multi-view、proprioception、subtask/situated planning、adaptive step/chunking、history、visual prompt 与 recovery plugins。
- GUMI 让人或 frontier agent 通过同一 GUI/semantic action space 采集示教。
- 轻量 VLM 仅用 rank-64 LoRA 更新约 3% 参数；零样本与微调模型共享动作接口和 embodiment interpreter。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| 10 个真实 object-to-plate/bowl tasks，10 trials/task | Average Success Rate ↑ | ZS 89%；FT 86% | RATS 57%（另有 π0.5 39%、GR00T 35%） | ZS +32 个百分点；FT +29 个百分点（相对 RATS） | PDF Table 2，p.10-11；Cross-Task |
| background/light/viewpoint/distractor/sim-to-real cross-environment | Average Success Rate ↑ | ZS 100%；FT 88%；FT sim-to-real 13/20 | RATS 65%；π0.5 与 GR00T sim-to-real 均 0/20 | ZS +35、FT +23 个百分点；sim-to-real 多 13/20 成功 | PDF Table 2，p.11；Cross-Environment |
| Franka/AgileX cross-embodiment，5 Plate tasks × 10 trials/arm | Average Success Rate ↑ | ZS 93%；FT 87% | RATS 52% | ZS +41、FT +35 个百分点 | PDF Table 2，p.11；Cross-Embodiment |
| 动作表示 2×2 消融，Block/Banana→Plate，共 20 次 | 任务成功 | 任意符号且无约定：1/20 | 任意符号+明确约定接近默认 semantic names+conventions | 未提供可安全读取的精确默认成功数；不作数值推断 | PDF Figure 10，p.16；正文同时报告无约定映射正确率 23.3% |

## 3. Dynin-Robotics: Omnimodal Unified Diffusion Vision-Language-Action Model

- **来源：** [arXiv](https://arxiv.org/abs/2609.13053) · [PDF](https://arxiv.org/pdf/2609.13053) · [Hugging Face](https://huggingface.co/papers/2609.13053)
- **发布日期：** 2026-09-11（近 7 天补充；超出严格窗口 5 天）
- **作者：** Hoeun Lee, Jaeik Kim, Jusang Oh, Jinhyeok Kim, Geon Choi, Hyeonggeun Kim, Jaeyoung Do
- **机构/单位：** AIDAS Lab; Seoul National University
- **领域标签：** manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** Dynin-Robotics 用一个 omnimodal masked-diffusion backbone 统一动作、下一视觉状态、目标图像和任务文本预测，并允许这些输出在推理时组合。
- **核心 insight：** 统一模型的收益不只来自多任务训练，还取决于推理时怎样组合预测：goal guidance 单独加入 action decoder 反而降低 OOD，而与 action/next-state joint denoising 结合才显著提升。

### 方法要点

- 继承 Dynin-Omni 的双向 Transformer 与离散 text/vision/speech token 空间，新增均匀量化的 action token block。
- 用同一序列接口训练 Policy、World Modeling、Task Understanding、Goal-State Prediction 四个目标，仅改变可见 span 与 masked target。
- Stage 1 在 48 个 OXE 数据集、约 130 万轨迹上持续预训练；Stage 2 对 LIBERO/VLABench/实机任务分别适配。
- 支持 action-only、goal-guided、action/next-state joint denoising、world-model reranking 等六种推理组合；dInfer 以 block commitment 加速动作 token 解码。

### 实验与结果

| LIBERO 四套件 macro-average | Success Rate (%) ↑ | 98.1 | X-VLA：98.1；ABot-M0：98.6 | 与 X-VLA 持平，低于 ABot-M0 0.5 个百分点 | PDF Table 2，p.19；Average 列 |
| LIBERO-Plus 七类 zero-shot perturbations | 平均 Success Rate (%) ↑ | 73.0 | OpenVLA-OFT：71.4；ABot-M0：81.6 | 相对 OpenVLA-OFT +1.6 个百分点；低于 ABot-M0 8.6 个百分点 | PDF Table 3，p.20 |

## 4. MessyMem: Learning-from-Doing Memory for Mobile Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2609.15976) · [PDF](https://arxiv.org/pdf/2609.15976)
- **发布日期：** 2026-09-14（近 7 天补充；超出严格窗口 2 天）
- **作者：** Anuva Banwasi, William Muckelroy III, Priya Sundaresan, Linfeng Zhao, Jeannette Bohg, Cherie Ho
- **机构/单位：** Stanford University
- **领域标签：** manipulation
- **灵巧手相关：** 否
- **一句话概括：** MessyMem 用持久 3D scene graph 作索引，把 interaction-derived properties/outcomes 与 linked visual keyframes 绑定到对象节点，让 mobile manipulator 能跨任务复用数小时前的经验。
- **核心 insight：** 长期机器人记忆不能只存结构化图或原始视频：前者丢失实例级细节，后者难检索且缺少空间落点；scene graph+interaction analyzer+linked keyframes 三者互补，才能同时做到可全局查询、由行动更新、细粒度回忆。

### 方法要点

- 以 SAM3 closed-set prompts 从 RGB-D 构建并增量关联 3D object scene graph，保留离开视野的节点与世界坐标。
- 每次 primitive 后让 VLM interaction analyzer 阅读多帧 collage，将 openable/locked/contents、success/failure 与原因写回目标节点；新证据覆盖过时结构化属性。
- 保存 interaction 前/后/最有信息帧及 scene-update frames，并将 full-resolution images、thumbnail、时间、动作和标签链接到 scene nodes。
- 检索先用 task+scene graph 对 metadata 做 text shortlist，再让 VLM 看 thumbnails 去重筛选，最后把 full-resolution frames、graph JSON 与当前观测交给 planner。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| RoboCasa365 25-task Long Horizon，连续 3+ hours | Task Progress (%) ↑ | MessyMem 80.0 [77.4,82.6] | SG+IA 65.2；RoboEXP 51.1；SG 49.1；SG+KF 47.9 | +14.8 个百分点相对 strongest ablation；+28.9 相对 strongest external baseline | PDF Table 1 与 Sec.5.2，p.7-8 |
| 50-trial simulation，Cluttered Pick / Locked-Unlocked | Task Progress (%) ↑ | MessyMem 84.0 / 99.0 | SG+IA 58.0 / 88.0；RoboEXP 53.0 / 70.0 | 相对 SG+IA +26 / +11 个百分点 | PDF Table 1，p.7 |
| 真实 TidyBot++ Office Drawer Search，n=5 | Overall Task Progress / Steps / SPL | 1.00 / 10.8 / 0.92 | SG+IA 0.87/11.0/0.82；SG+KF 0.60/17.0/0.40；SG 0.40/15.4/0.34 | Task Progress 相对 SG+IA +0.13 | PDF Table 2，p.8 |
| 真实 TidyBot++ Sock Pairing，n=6 | Task Progress ↑ | MessyMem 1.00 | SG+IA 0.67；SG+KF 0.67；SG 0.50 | +0.33 相对 strongest ablations | PDF Figure 3 邻近正文，p.9 |
