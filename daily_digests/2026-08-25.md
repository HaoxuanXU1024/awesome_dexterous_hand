## 1. ForeTime-VLA: Causal Future-Token Distillation from a World Action Model for Conveyor-Belt Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2608.20735) · [PDF](https://arxiv.org/pdf/2608.20735)
- **发布日期：** 2026-08-21（近 7 天补充；超出严格窗口 4 天）
- **作者：** Siyuan Ma, Yutian Zhang, Boshi Zhang, Qinglian Wu, Jiaqi Zhai, Dong Wei, Xiaojin Huang
- **机构/单位：** 1Tsinghua University, Beijing, China; 2Shanghai Artificial Intelligence Laboratory, Shanghai, China; 3Harbin Institute of Technology, Harbin, China
- **领域标签：** foundation_models, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** ForeTime-VLA 将离线 world-action-model 的未来信息蒸馏为因果 future tokens、phase 和 transition-horizon 预测，用于 conveyor-belt manipulation。
- **核心 insight：** 不在部署时运行视频 world model，而是让八帧历史编码器预测 action-equivalent future code，并同时调节 VLM prefix 与 action expert；收益主要集中在接触时刻和末端姿态。

### 方法要点

- 冻结 Fast-WAM-derived video VAE，将当前/未来 latent 与 robot state 压缩为 whitened 64-D action-equivalent target。
- 八帧 causal history encoder 联合预测 future code、manipulation phase 和 normalized time-to-transition；四个 future tokens 与一个 phase token 条件化 dense pi0.5。
- 保留 flow-matching action target，加入 cosine、relational geometry、phase、transition-time 和 action-equivalence loss；WAM 只在训练离线使用。

## 2. Just Noticeable Difference Modeling for Token Compression in Vision-Language-Action Models

- **来源：** [arXiv](https://arxiv.org/abs/2608.21247) · [PDF](https://arxiv.org/pdf/2608.21247)
- **发布日期：** 2026-08-21（近 7 天补充；超出严格窗口 4 天）
- **作者：** Zhuoyuan Li, Rui Zhao, Jin Wang, Hanwei Zhu, Cong Zhang, Giuseppe Valenzise, Weisi Lin, Kin-Man Lam
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** embodied_ai, foundation_models, vla
- **灵巧手相关：** 否
- **一句话概括：** Action-JND 用 VLA 的下游 action deviation 定义视觉 token 的可容忍变化，并据此指导 KV-cache reuse 与 token pruning。
- **核心 insight：** 与 attention/saliency 等间接线索不同，token 是否可压缩由语言条件下的 action response 直接决定；在 aggressive compression 时更能保护 action-critical tokens。

### 方法要点

- 训练轻量 token-wise JND estimator，以 action-token KL 或 continuous action regression 估计视觉 token 的 action tolerance。
- 将 Action-JND ranking 接入 soft/strict_guarded KV-cache reuse 和 budgeted token pruning，并用 safe candidate pool 保护低容忍 token。
- 在 OpenVLA 与 OpenVLA-OFT 上使用 LIBERO Spatial/Object/Goal/Long，比较 FastV、SparseVLM、DivPrune 和 VLA-Cache。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| LIBERO/OpenVLA，KV-cache reuse 60% | 平均 success Acc. | Action-JND 56.90% | VLA-Cache 33.20% | +23.70 percentage points | Table I，PDF p.10；Spatial/Object/Goal/Long/Acc. 列与 reuse ratio=60% 行已核对。 |
| LIBERO/OpenVLA-OFT，KV-cache reuse 80% | 平均 success Acc. | Action-JND 89.55% | VLA-Cache 79.45% | +10.10 percentage points；latency 91.05 ms vs vanilla 137.43 ms | Table II，PDF p.11；Acc./Latency 列已核对。 |
| LIBERO/OpenVLA，token pruning 87.5% | 平均 success Acc. / relative FLOPs / latency | 42.00% / 33.06% / 30.16 ms | VLA-Cache 30.35%；vanilla 52.88 ms | +11.65 pp vs VLA-Cache；control frequency 33.15 Hz vs vanilla 18.91 Hz | Table III，PDF p.12；pruning ratio、Acc.、Rel. FLOPs、Latency、Freq. 表头已核对。 |

## 3. Logic-VLA: A Temporal Logic Conditioned Vision-Language-Action Model

- **来源：** [arXiv](https://arxiv.org/abs/2608.20556) · [PDF](https://arxiv.org/pdf/2608.20556)
- **发布日期：** 2026-08-20（近 7 天补充；超出严格窗口 5 天）
- **作者：** Celina Shiyu Wang, Yiqi Zhao, Junjie Ye, Yue Wang, Jyotirmoy V. Deshmukh
- **机构/单位：** 1Thomas Lord Department of Computer Science, University of Southern California
- **领域标签：** navigation, vla
- **灵巧手相关：** 否
- **一句话概括：** Logic-VLA 用语义预训练的 syntax-graph STL encoder 和 satisfying/violating trajectory preference optimization，让单一 pi0.5 VLA 适应不同 temporal-logic 要求。
- **核心 insight：** 把形式要求作为结构化条件并比较满足/违背轨迹，能提高 STL satisfaction，同时避免直接最大化 robust semantics 带来的 nominal NL task 崩溃。

### 方法要点

- 在 Isaac Sim quadcopter navigation 中，以 STL syntax graph encoder 编码 predicate、temporal operators 和 Boolean composition。
- Stage 1 用 satisfying demonstrations 做 STL-conditioned SFT；Stage 2 用 matched satisfying-violating pairs 做 trajectory-level IPO，并加入 preferred-rollout anchor。
- 在 Seen、Unseen Parameter、Unseen Structure 三种 formula split 上评估 STL satisfaction、robust semantics 和 NL task success。

### 实验与结果

| Unseen Parameter formulas | STL satisfaction / NL task success | Logic-VLA 74.8% / 92.2% | Base 50.0% / 93.9% | +24.8 pp STL；NL task -1.7 pp | Table I，PDF p.6；Unseen Parameter 列已核对。 |
| Unseen Structure formulas | STL satisfaction / NL task success | Logic-VLA 82.0% / 87.5% | Base 56.8% / 89.3% | +25.2 pp STL；NL task -1.8 pp | Table I，PDF p.6；Unseen Structure 列已核对。 |

## 4. A Collaborative Multi-Modality Interaction for VLA-based End-to-End Autonomous Driving

- **来源：** [arXiv](https://arxiv.org/abs/2608.20890) · [PDF](https://arxiv.org/pdf/2608.20890)
- **发布日期：** 2026-08-21（近 7 天补充；超出严格窗口 4 天）
- **作者：** Jingtao Sun, Xiaohai He, Yike Zhang, Dong Huang, Yaonan Wang, Ajmal Mian, Mike Zheng Shou
- **机构/单位：** A Collaborative Multi-Modality Interaction
- **领域标签：** vla
- **灵巧手相关：** 否
- **一句话概括：** CMMI 将 camera、LiDAR、language 与 ego state 做 affinity-guided optimal transport 和 distribution-consistent modality transfer，再用 multi-trajectory planning/refinement 做 VLA end-to-end driving。
- **核心 insight：** 结构化双向跨模态交互和多候选轨迹优化同时改善场景感知与长时规划，在 NAVSIM、Bench2Drive、nuScenes 和 Argoverse 2 上形成闭环证据。

### 方法要点

- Affinity-Guided Optimal Transport 建立 heterogeneous modality 的两向交互；Distribution-Consistent Modality Transfer 将特征对齐到统一 Gaussian latent space。
- Multi-Modality Multi-Trajectory Planning 生成多候选 ego trajectories，再用 Perception-Oriented Trajectory Refinement 融合风险 cost map。
- 以 Janus-1.5B 为 VLA backbone，输入 camera+LiDAR+language/ego status，在 NAVSIM open-loop、Bench2Drive closed-loop 和 nuScenes/Argoverse 2 perception 上评估。

### 实验与结果

| Bench2Drive closed-loop，44 interactive scenarios | Driving Score / Route Completion / Infraction Score / Success Rate | 77.45 / 88.23 / 0.90 / 56.00 | VLR-Driver 75.01 / 86.09 / 0.87 / 50.00 | +2.44 / +2.14 / +0.03 / +6.00 | Table 3 与相邻正文，PDF p.10；44-scenario protocol 和 core metric 列已核对。 |
