## 1. HAF: Adapting Generalist VLAs to Humanoid Whole-Body Loco-manipulation via Hierarchical Action Flow and Spectral Latent RL

- **来源：** [arXiv](https://arxiv.org/abs/2608.16837) · [PDF](https://arxiv.org/pdf/2608.16837)
- **发布日期：** 2026-08-17（近 7 天补充；超出严格窗口 3 天）
- **作者：** Langzhe Gu, Chengkai Hou, Meng Li, Xinhua Wang, Jiaming Liu, Xinyuan Lv, Bowei Zhang, Shuanghao Bai, Guangrun Li, Jingyang He, Gaole Dai, Ziluo Ding et al.
- **机构/单位：** 1State Key Laboratory of Multimedia Information Processing, School of Computer Science,; Peking University 2Beijing Innovation Center of Humanoid Robotics 3Nankai University; 4Xi’an Jiaotong University
- **领域标签：** foundation_models, humanoid, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** HAF 先按 locomotion/head -> waist -> dual-arm 的运动学依赖分阶段生成全身动作，再在冻结 VLA 的 DCT 压缩噪声空间中做 offline-to-online SAC 适配。
- **核心 insight：** Humanoid loco-manipulation 的主要难点不是单个关节预测，而是底盘、躯干和双臂之间的因果依赖；HAF-VLA 用逐级扩展动作空间和跨阶段 KV cache 保留这种依赖，HAF-Steer 则只优化低频 latent noise，降低真机 RL 的维度和高频危险探索。

### 方法要点

- 以 pi0.5 flow-matching VLA 为基础，将动作生成拆成三阶段：locomotion/head、加入 waist、再加入 dual-arm manipulation；后续阶段可修正前序维度，最终只执行第三阶段完整 action chunk。
- 把早期阶段的 clean actions 重新编码为 cross-stage KV caches，并用 stage embedding 区分当前生成阶段，从而让后续动作显式条件化于已生成的底盘与姿态。
- HAF-Steer 通过 flow reversal 将 demonstration action 映射回初始噪声，沿时间维做 DCT 并仅保留前 8 个系数；先做 spectral behavior cloning，再用混合 offline/online replay 的 BC-regularized SAC 优化，VLA backbone 全程冻结。

## 2. DreamX-Phi 1.0: Action-Conditioned Video World Model for Robotic Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2608.13489) · [PDF](https://arxiv.org/pdf/2608.13489) · [Hugging Face](https://huggingface.co/papers/2608.13489)

- **核心 insight：** 动作条件视频的关键不只是逼真，而是让每只机械臂沿指定 3D 轨迹运动并保持小物体接触一致性；论文将几何动作约束、图像平面运动线索、场景深度与 object-relational teacher 拆成互补监督。

### 方法要点

- 以 Wan2.2-TI2V-5B 为 backbone，输入 observed RGB、language instruction 与外部给定的双臂 end-effector poses/gripper states，预测 future RGB video。

- 用 SAM3 mask 重加权 object RGB loss、Depth Anything 3 depth latent branch 与 frozen V-JEPA Gram-relation loss 约束几何/物体一致性，最后用 DMD+adversarial training 蒸馏 few-step student。

## 3. $τ_0$-VLA: a Hierarchical Robot Foundation Model with World-Model-Guided Test-Time Computation

- **核心 insight：** 长时机器人失败常来自错误的高层承诺，而不是低层动作不够精确；tau0-VLA 在执行前用 proposal-world model-value model-reflection 比较候选后果，并用可纠错 execution memory 记录真实进度，从而把额外计算集中到不确定决策。

### 方法要点

- 低层策略以 Qwen3.5-2B 加 Mixture-of-Transformers action expert，在统一 40-D masked state/action space中做 conditional flow matching，覆盖 fixed-base、mobile、bimanual 等多种 embodiment。

## 4. EATR-Stereo: Embodiment-Aware Token Routing of Paired Stereo Evidence for Humanoid Vision-Language-Action Control

- **来源：** [arXiv](https://arxiv.org/abs/2608.17453) · [PDF](https://arxiv.org/pdf/2608.17453)
- **发布日期：** 2026-08-18（近 7 天补充；超出严格窗口 2 天）
- **作者：** Songwei Wu, Rui Zhao, Fan Yang, Zhongqiang Nie, Zhiduo Jiang, Wandong Sun, Yuwei Li, Jian Hu, Yang Liu, Hong Liu
- **机构/单位：** 1Harbin Institute of Technology, 2Honor
- **领域标签：** humanoid, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** EATR-Stereo 保留 pretrained VLA 的 primary-view tokens，用 primary-query cross-attention 构造对齐的 CVAT 辅助流，再按身体分段 proprioception 逐 token 路由 stereo evidence。
- **核心 insight：** 头戴双目相机的价值不只是多一张图，而是同步对应、视差和互补遮挡；将辅助视图直接拼接或改写主视图会破坏 pretrained semantic path，EATR-Stereo 因而把主流保留、辅流对齐，并让机器人姿态决定何时使用辅助证据。

### 方法要点

- 冻结 Cosmos-2B/GR00T N1.7 的 vision-language backbone，primary tokens M 保持不变；以 M 为 query、auxiliary tokens A 为 key/value 做 cross-view attention，得到一一对应的 CVAT C。
- 将 37-D proprioceptive history 按 legs、arms/hands、head、waist、base pose 五组编码，attention/mean pooling 后与 M、C、差值和乘积共同输入 token-wise sigmoid router。
- 路由后的 auxiliary tokens 与 language、primary tokens 一起条件化 flow-matching action expert；部署端用 asynchronous buffer 与 local cubic B-spline 平滑 action-chunk 边界，外部 VLM 仅做 subtask completion check。

## 5. Teach and Grow: An Agent-Centered Architecture for General Robot Learning

- **来源：** [arXiv](https://arxiv.org/abs/2608.17209) · [PDF](https://arxiv.org/pdf/2608.17209)
- **发布日期：** 2026-08-17（近 7 天补充；超出严格窗口 3 天）

- **机构/单位：** 论文首页未可靠提取
- **领域标签：** embodied_ai, robot_learning, vla
- **灵巧手相关：** 否
- **一句话概括：** Teach-and-Grow Learning 把少量成功示范抽象为可验证、可保存、可重组的 Skill Blocks，并由多模态 Agent 在每个语义边界根据物理反馈选择工具、重规划或请求针对性教学。
- **核心 insight：** 论文反对把每个局部能力缺口都变成全局 policy retraining：新能力应作为有 scope、grounding、executor、success test 和 recovery 的显式对象被局部加入，Experience Memory 则保存失败与修复，使后续任务从已验证经验开始。

### 方法要点

- 跨多条 demonstration 按语义 state change 对齐 segments，合成 acquisition/release 等 Skill Block；运行时重新绑定对象、几何、抓取、路径和 controller，而不是回放原轨迹。
- Agent 检索并组合 blocks，但不直接输出高频 motor command；每个 block 调用 learned policy、geometry、planner 或 controller，执行后由 fresh observation 验证 intended effect，再决定继续、重观测、换路线或 targeted teaching。
- Skill Library 保存可执行 contract，Experience Memory 保存成功、失败和 repair；论文进一步提出 effective reusable experience X 与 future error/teaching demand 的 power-law hypothesis，但当前只给机制试验，纵向 scaling curve 留待未来。

## 6. FetchMan: Learning Visual Humanoid Loco-Manipulation Policies from Simulated Experiences

- **来源：** [arXiv](https://arxiv.org/abs/2608.17027) · [PDF](https://arxiv.org/pdf/2608.17027)
- **发布日期：** 2026-08-17（近 7 天补充；超出严格窗口 3 天）
- **作者：** Omar Rayyan, Zhi Li, Max Argus, Yuxin Jiang, Chang Yu, Chenfanfu Jiang, Yuchen Cui
- **机构/单位：** 1University of California, Los Angeles 2Allen Institute for AI 3University of Washington
- **领域标签：** humanoid, manipulation, sim_to_real
- **灵巧手相关：** 否
- **一句话概括：** FetchMan 用大规模 scripted simulation behavior cloning 建立 humanoid loco-manipulation prior，再以 sparse-reward Flow-GRPO 修复隐藏 phase boundary 导致的 imitation ceiling，并零样本部署到 Unitree G1。
- **核心 insight：** 脚本专家依赖 policy 看不到的 navigation/reach/grasp phase index，因此增加同分布 demonstrations 在 50k 后也无法消除结构性歧义；从较强 BC prior 出发的 on-policy RL 可以直接优化成功率并学会更平滑的 locomotion-to-manipulation handoff。

### 方法要点

- 在 MolmoSpaces 的 150k+ houses / 50k+ objects 中采样场景、目标、G1 起点和可行 grasp，用 A*、Mink IK 与 phase-based privileged controller 生成 15-D whole-body action demonstrations，并做视觉、相机、物理和动作随机化。
- policy 使用 frozen DINOv3 ViT-B/16 编码 head fisheye 与 wrist RGB，DiT-style flow action head 预测 H=16 action chunk；11 个 pose/joint dimensions 改为 relative delta targets，部署每次执行前 8 步。
- Flow-GRPO 将 flow sampler 随机化为可计算 likelihood 的 Gaussian transitions；每组从相同 task state rollout 8 次，用 group-relative binary success advantage 更新，丢弃全成功或全失败组。
