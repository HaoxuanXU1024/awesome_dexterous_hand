## 1. On Agentic Manipulation Policies

- **发布日期：** 2026-11-06（近 7 天补充；超出严格窗口 4 天）

- **领域标签：** dexterous, manipulation, vla

- 同一 harness 横跨 RoboLab-120、CaP-Gym、RoboDojo 和 Franka Research 3 真机，仅替换 robot/camera 描述。

## 2. SUGARv2: Learning Diverse Visual Humanoid Loco-Manipulation Skills from Synthesized Interaction References

- **来源：** [arXiv](https://arxiv.org/abs/2611.09266) · [PDF](https://arxiv.org/pdf/2611.09266)
- **发布日期：** 2026-11-06（近 7 天补充；超出严格窗口 4 天）
- **作者：** Tianshu Wu, Tianxiang Gui, Yue Chen, Tingxu Liu, Ziye Peng, Guangjie Yang, Xiangqi Kong, Ye Shi, Jingya Wang, Hao Dong
- **机构/单位：** 1CFCS, School of Computer Science, Peking University; 2ShanghaiTech University 3Beihang University
- **领域标签：** humanoid, manipulation, sim_to_real
- **灵巧手相关：** 否
- **一句话概括：** SUGARv2 用可复用 task template 合成 humanoid–object interaction references，再以统一 mimic reward 训练 privileged teacher 和视觉策略，覆盖五类 humanoid loco-manipulation。
- **核心 insight：** 扩展 humanoid 操作的瓶颈不只是数据量，而是每个空间配置都要重做示范和 reward；把任务抽象成 key poses、空间关系与 contact labels，可低成本实例化参考轨迹并复用同一训练目标。

### 方法要点

- GPT-6 Astra 生成按交互阶段排序的 task template，包含 whole-body poses、robot/object 与 hand/object 空间关系和 intended contact labels。
- 对每个 robot/object/goal 配置实例化 keyframes 和 timing，用 motion generation model 生成连续 whole-body motion，再由 interacting hands 构造 object trajectory。
- 冻结 pretrained whole-body controller，先用 privileged state/reference 和 tracking/interactions/regularization mimic reward 训练 teacher。
- 视觉 student 接收 egocentric RGB 与 proprioception，以 teacher distillation 初始化，再保留 teacher supervision 做 reference-based RL，并加入 object/appearance domain randomization。

## 4. Say the Same, Act Differently: Diagnosing and Steering Text-Action Divergence in Reasoning VLAs

- **来源：** [arXiv](https://arxiv.org/abs/2611.04166) · [PDF](https://arxiv.org/pdf/2611.04166) · [Hugging Face](https://huggingface.co/papers/2611.04166)
- **发布日期：** 2026-11-03（近 7 天补充；超出严格窗口 7 天）
- **作者：** Zihao Feng, Qingzhao Zhang, Chunyu Xia, Bo Yu, Z. Morley Mao, Ramesh Govindan
- **机构/单位：** 1University of Southern California 2University of Arizona 3General Motors
- **领域标签：** embodied_ai, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** 该论文发现 reasoning VLA 的可读 rationale 与连续 action 并非安全绑定：沿 text-neutral action subspace 轻微移动共享 hidden state，可让语言逐字不变而把动作推向危险方向。
- **核心 insight：** 自然语言是连续表示的 many-to-one 离散读出；动作最敏感方向几乎正交于当前 text-loss gradient span，因此‘解释没变’不能证明动作没变。

### 方法要点

- 在 Alpamayo 与 InstructVLA 的共享 text/action hidden state 上计算 action-output Jacobian，取得局部最敏感方向 d_act。
- 用 clean-token NLL 与 target-margin drop 的梯度做 Gram–Schmidt，形成 rank-2 active text-loss span。
- 将 d_act 对 text span 正交投影后的残差归一化为 TNAS direction，以 fixed text-KL/equal-norm probes 验证 action-selective/text-neutral 性质。
- 在 full image 或共享 patch 的 PGD 中加入 hidden shift 与 d_TNAS alignment，同时保留 action-displacement 和 text-preservation。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| Alpamayo，154 个 obstacle-annotated driving clips，full-image TNAS PGD λcos=30 | Silent Collision / Exact Rationale Match | 52.6% / 89.5% | Action-only PGD 4.55% / 9.5%；Text-preserving PGD 48.7% / 83.0% | 对 Text-preserving +3.9pp / +6.5pp | PDF p.7 Table 1；核对 Open loop Silent Coll. 与 Free gen. Exact 两列。 |
| InstructVLA，200 Bridge-distribution examples，full-image TNAS λcos=0.20 | Exact Response Match / normalized Action Shift / teacher-forced KL | 85.0% / 1.73 / 2.06×10^-2 | Text-preserving PGD 77.5% / 1.97 / 3.46×10^-2 | exact +7.5pp；KL -40.5% | PDF p.8 Table 2；核对 Fixed-prefix、Free gen. 与 λcos=0.20 行。 |

## 5. VICTR: Value-Informed In-Context Learning for Vision-Language-Action Models

- **来源：** [arXiv](https://arxiv.org/abs/2611.08698) · [PDF](https://arxiv.org/pdf/2611.08698)
- **发布日期：** 2026-11-05（近 7 天补充；超出严格窗口 5 天）
- **作者：** Luca Macesanu, Tianluo Zhang, Aditya Patil, Archit Sharma, Kevin Angers, Christopher M. Clark, Chen Feng, Juexiao Zhang
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** foundation_models, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** VICTR 用 reference-conditioned value estimator 估计当前任务进度，再检索同阶段 demonstration chunk 供 π0.5 in-context 生成动作，而非只按视觉相似度检索。
- **核心 insight：** 对未见任务，最有用的 context 不一定长得最像当前画面，而是处于相同执行阶段；reference demo 把 value 变成 task-relative progress，可跨任务校准检索。

### 方法要点

- 部署时每 task 提供 10 条 demonstration；最短成功示范作为 IC-VFE reference，所有示范切成 action-aligned candidate chunks。
- IC-VFE 以 current observation、language instruction 和 reference video 输出 0–1 progress；reference frame tokens 做 patch merging 以适应 context budget。
- 按当前与候选 chunk 的 progress distance 取最近一块，也比较 DINOv2 vision-only 与 vision+value retrieval。
- π0.5 IC-VLA 输入 retrieved observation/action FAST tokens 与当前 query，用 block-causal attention 预测 30-step action chunk。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| 16 个 YOR 真机任务：8 InD + 8 OOD，10 rollouts/task | OOD Success Rate / Task Progress | VICTR 23.8% / 55.5% | fine-tuned π0.5 6.2% / 28.9%；RICL-π0.5 no-interp 15.0% / 42.1% | 对 π0.5 +17.6pp success、+26.6pp progress | PDF p.5 Fig. 4 与紧邻正文；核对 OOD/InD、solid success 与 light progress。 |
| 16 evaluation tasks，online VFE 对 human-annotated progress | Kendall τb / Pearson r（OOD） | IC-VFE 0.52 / 0.65 | RECAP 0.43 / 0.57；Robometer FT 0.33 / 0.46；no context 0.38 / 0.49 | 对 RECAP +0.09 / +0.08 | PDF p.6 Table I，核对 In-domain/Out-of-domain 双组表头。 |
| 30 unseen LIBERO-100 tasks，π0.5 backbone，top-k=1，无 action interpolation | Success Rate | VICTR 45.870% | Non-ICL 37.800%；RICL 41.200% | +8.07pp / +4.67pp | PDF p.9 Appendix Table III；核对 backbone、Top-k 与 Action interp. 列。 |

## 6. DobotTrack: Target-Grounded Vision-Language-Action Learning for Embodied Person Tracking

- **作者：** Shengjun Deng, Yinghan Zhang, Chengrui Wei, Liu Liang, Songyuan Liu, Pengkun Zheng, Yajun Zheng, Ying Zhang, Yuan Tian, Xi Li, Teng Wang
- **机构/单位：** 1Foshan University 2Tsinghua University; 3Dobot Robotics 4The University of Hong Kong; *Corresponding authors: tengwang@connect.hku.hk, yinghan-24@mails.tsinghua.edu.cn
- **领域标签：** embodied_ai, vla
- **灵巧手相关：** 否
- **一句话概括：** DobotTrack 用 mask/box grounding 监督和 Q-identity 压缩历史视觉，在 0.8B 规模下把语言指定人物的身份保持、轨迹预测与端侧部署统一起来。
- **核心 insight：** 具身人物跟踪的关键不是把所有历史帧塞给 VLA，而是先用已预测的目标框提取身份与空间线索，再用少量 learned queries 联合聚合目标区域和全图上下文；显式 target grounding 比单纯轨迹模仿或未来特征预测更有效。

### 方法要点

- 基于 InternVL3 构建 0.8B VLA：输入 appearance description、8 帧 RGB 历史，联合输出当前 target mask、bounding box/visibility 与 8 个未来 egocentric waypoints。
- 用 SAM2 decoder 对 mask token 做像素级分割，grounding head 回归 box，action head 回归轨迹；mask 与 box token 位于 waypoint tokens 之前，使动作可因果访问目标表征。
- Q-identity 以历史 cached box 选取 target-region features，用 16 个 learned queries 做 target-conditioned self-attention，再对 full-image features 做 cross-attention；7 帧历史从 7×256 压为 7×16 tokens。
- 训练混合 EVT-Bench 约 180 万 sequence samples 与四足机器人采集的 126 episodes/596,323 mask-annotated frames；视觉编码器冻结，其余模块联合优化。
