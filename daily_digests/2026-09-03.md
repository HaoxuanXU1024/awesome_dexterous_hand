## 1. EmbodiedSkills: A Unified Framework for Orchestrating, Training, and Deploying VLA Agents

- **来源：** [arXiv](https://arxiv.org/abs/2609.01281) · [PDF](https://arxiv.org/pdf/2609.01281)
- **发布日期：** 2026-09-01（近 7 天补充；超出严格窗口 2 天）
- **作者：** Wei Wang, Wenqiao Zhang, Yutong Lin, Yuqian Yuan, Tianwei Lin, Jinhao Mao, Zhenxuan Fan, Mingjian Gao, Yang Dai, Wentong Li, Zheqi Lv, Zheng Dong et al.
- **机构/单位：** 1College of Computer Science and Technology, Zhejiang University,2Nanjing University of; Aeronautics and Astronautics,3Cornell University,4Universal Ubiquitous AI Co., Ltd.,5National; University of Singapore,6Hangzhou DEEP Robotics Technology Co., Ltd.; components and can support optional online adaptation when interactive feedback is available. We
- **领域标签：** embodied_ai, foundation_models, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** EmbodiedSkills 把 VLA agent 的每次 skill decision 变成带前置检查、执行、结果验证和恢复的闭环执行提案。
- **核心 insight：** 长时任务的关键不只是 action prediction，而是用固定 skill interface 将 planning、bounded VLA execution、verification 和 recovery 组织成可检查轨迹。

### 方法要点

- typed task state 与 phase-structured executable skills
- planner 产生 semantic subgoals；低层 VLA 按 subgoal 输出 bounded action chunks
- 每个 chunk 后收集新证据，由 verifier 决定继续、推进或恢复；结构化 trace 支持组件级监督和可选 online adaptation

## 2. REFACTOR-VLA: Unsupervised Library Learning of Typed Motor Programs

- **来源：** [arXiv](https://arxiv.org/abs/2609.01215) · [PDF](https://arxiv.org/pdf/2609.01215)
- **发布日期：** 2026-09-01（近 7 天补充；超出严格窗口 2 天）
- **作者：** Riyaaz Shaik, Chandru Venkataraman
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** foundation_models, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** REFACTOR-VLA 用 BEK 动力学等价核、typed-lambda 程序和 MDL/return gates，把连续动作片段压缩成可复用 motor-program library。
- **核心 insight：** world model 的训练目标比参数规模更决定 skill clustering：188M 加 SupCon InfoNCE 在四个 LIBERO suite 都优于无 InfoNCE，430M 反而退化。

### 方法要点

- sleep phase 用 frozen world model rollout 的 value/Wasserstein BEK 做 KMeans 聚类
- wake phase 用 Hindley–Milner 风格 Typed Program Emitter 生成程序，LCAD 输出 16-step rectified-flow action chunk
- 候选 abstraction 需同时通过 BEK soundness、return-preservation 与 MDL-gain gate

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| LIBERO 四 suites；n=3 seeds；BEK + InfoNCE | NMI | object 0.462±0.021；spatial 0.867±0.025；goal 0.915±0.013；LIBERO-10 0.754±0.010 | 无 InfoNCE：0.285/0.475/0.493/0.719 | 四套均提升；mean head-to-head gain +0.184 | PDF Table 1 / p.6；Table 2 / p.7 |
| world model capacity falsification | NMI change 188M→430M | object 0.285→0.245；spatial 0.475→0.329；goal 0.493→0.475；LIBERO-10 0.736→0.646 | 188M same objective | 四套均下降 | PDF p.7，§4.6 |
| real-LIBERO library rewrite；libero_object | demo rewrite coverage / LCAD velocity error | 256/256 demos；使用 2/3 abstractions；Δ velocity error −0.0059 | no-library baseline | 误差变化在 ±0.02 内 | PDF p.5；§3.3 |

## 5. Knowing When to Stop: Adaptive Action Chunking via Internal Cross-Attention Dynamics in VLAs

- **来源：** [arXiv](https://arxiv.org/abs/2609.00908) · [PDF](https://arxiv.org/pdf/2609.00908)
- **发布日期：** 2026-09-01（近 7 天补充；超出严格窗口 2 天）
- **作者：** Runze Xu, Xiaolong Shan, Shuang Dai, Yu Wang, Jincheng Yu
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** 该方法用 action expert 内部 cross-attention entropy 的持续高平台作为在线信号，自适应截断 action chunk。
- **核心 insight：** 预测 horizon 越长且 attention 越分散时，动作与当前 observation 的 grounding 变弱；无需训练即可动态缩短 chunk，在成功率和推理频率间取得更好折中。

### 方法要点

- 计算 action-to-observation cross-attention entropy 及其平滑高平台
- 当高 entropy plateau 持续满足阈值时截断，否则执行更长 chunk
- 不改模型参数，统一在 π0.5 与 X-VLA、RoboTwin、LIBERO 和真实任务上评测

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| RoboTwin 2.0；π0.5；10 tasks×3 seeds×100 rollouts | average success rate | Ours 62.9%；average execution length 18.11 | best fixed chunk=10：61.6%；SA 57.6%；MS 57.0% | +1.3 points vs strongest fixed baseline | PDF Table II / p.6 |
| RoboTwin 2.0；X-VLA | average success rate | Ours 79.0% | best fixed chunk=30：76.1% | +2.9 points | PDF Table III / p.7 |
| LIBERO 四 suites；π0.5 | success rate average | Ours 97.25% | best fixed-6 94.88% | +2.37 points；LIBERO-Long 94.5% vs best fixed 90.0% | PDF Table IV / p.7 |
| real-world Hang Mug/Stack Cups/Pen Tidying；20 trials/task | average success | Ours 61.7% | best fixed 47.5%；SA 55% | +14.2 points vs best fixed；+6.7 vs SA | PDF Table V / p.8 |
| π0.5 inference latency on A100 | latency per chunk | Ours 0.2725 s | Fixed 0.2661 s；MS 0.2956 s；SA 0.2728 s | 比 MS 少 0.0231 s | PDF Table VI / p.8 |

| Code | Model | Data | Hardware / simulator | Difficulty | 最现实路径 |
|---|---|---|---|---|---|
| 公开 PDF 未明确仓库链接；方法依赖现有 π0.5/X-VLA attention weights | π0.5、X-VLA；固定 k=5、τ=0.01、η=0.95（LIBERO π0.5 用 k=3） | RoboTwin 2.0、LIBERO、三项真实双臂 ARX 任务 | 仿真可先复现；真实实验需要 ARX R5 follower/X5 leader、相机和 A100 latency profile | medium | 先在 π0.5 RoboTwin 复现 Table II，再验证 LIBERO 与真实任务 latency |
