## 1. PDRVLA: A Vision-Language-Action Model with Physical Dynamics Representations

- **来源：** [arXiv](https://arxiv.org/abs/2610.37381) · [PDF](https://arxiv.org/pdf/2610.37381) · [Hugging Face](https://huggingface.co/papers/2610.37381)
- **发布日期：** 2026-10-27（近 7 天补充；超出严格窗口 1 天）
- **作者：** Hanqing Wang, Zhaotian Cai, Ruichuan An, Bohan Zeng, Tao Zhang, Yilin Chen, Xu Jiang, Kaiquan Chen, Chongyang Wu, Haoran Li, Fan Yang, Mingan Lin et al.
- **机构/单位：** 1Peking University 2JD.com
- **领域标签：** embodied_ai, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** PDRVLA 用仅占 4B backbone 约 1.4% 参数的 Physical Dynamics Module 抽取 physical tokens，以未来 RGB/depth/flow feature 与 frozen video world model 训练，部署时无需生成视频即可给 action expert 提供动力学条件。
- **核心 insight：** 世界模型最实用的角色未必是在线 rollout，而是训练期把中间层 VLM features 塑造成可预测未来外观、几何和运动的 compact tokens，再让动作头直接消费这些 tokens。

### 方法要点

- 从 Qwen3.5-4B 第 8/32 层特征用 50 个 learnable queries 和 4-block query Transformer 提取 50×2560 physical tokens。
- 预训练同时做未来 RGB/depth/optical-flow latent 的 direct prediction，并用 frozen LingBot-Video world model 提供 auxiliary flow-matching supervision。
- action expert 将 physical tokens、final-layer VLM features 与 proprioception 拼接，用 conditional flow matching 和 4-step Euler 生成 8-action chunk。
- 将公开机器人/UMI/仿真数据扩展为统一 58-D cross-embodiment action，并加入 1.1M subtask VL examples 与 2.56M ECoT keyframes。

## 2. GAWM: A Compact Latent World-Action Model for Multi-Task Robot Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2610.37091) · [PDF](https://arxiv.org/pdf/2610.37091)
- **发布日期：** 2026-10-27（近 7 天补充；超出严格窗口 1 天）
- **作者：** Yang Liu, Xiaoli Liu, Liuzhao Li, Yuduo Song, Muyuan Liu, Xiang Gao
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** manipulation, robot_learning, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** GAWM 用 frozen DINOv3 + 4–6M task-conditioned latent predictor 在两个未来 horizon 预测 dense spatial features，再由 ACT-style decoder 一次前向回归 action chunk，以 38/77M 参数实现低延迟 closed-task world-action control。
- **核心 insight：** 对于固定任务集，future conditioning 不需要大 VLM 或视频生成器：由 task code 直接预测未来 latent layout，并让每个 action step 按时间位置 attend current/near/far tokens，便可把 foresight 变成轻量 reactive policy。

### 方法要点

- frozen DINOv3 ViT-S/16 多层 patch features 经每视角 64-query adapter 压缩为 visual tokens。
- bidirectional predictor 以 task code 为条件，残差式并行预测 chunk midpoint 与 endpoint 两组 latent tokens，不输入候选 actions。
- training-only patch decoder 用未来帧的 frozen dense features 做 cosine supervision，并配 current reconstruction 与 VICReg-style token regularization。
- ACT-style action decoder 从 current、near/far forecast、state 与 task token 一次前向回归整段 action；部署时删除 patch decoder，无搜索/扩散采样。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| RoboTwin 2.0 mixed protocol，50 clean + 500 randomized demos/task | Success Rate clean/randomized | GAWM-S 93.94% / 93.10% | LaWAM 92.64%/89.80%；Fast-WAM 91.88%/91.78%；LingBot-VA 92.93%/91.55% | 对各 setting 最强 baseline +1.01pp / +1.32pp | PDF p.5 Table I；核对 mixed protocol、参数计数与评测 episode 注释。 |
| RoboTwin 191k-step short schedule world-model ablation | Clean Success Rate | GAWM-S 90.7% | w/o world model 18.8% | +71.9pp，95% paired per-task bootstrap [65.2,78.0] | PDF p.5 Table II；该差值仅适用于 shortened schedule。 |
| Tianji Marvin Pro yellow-bottle real robot，50 closed-loop trials | Success Rate / median latency | GAWM-S 46/50（92%）/ 9.3ms | π0.5 39/50（78%）/ 63.8ms | +14pp；约 6.9× lower median latency | PDF p.7 Table III；GAWM 60k fine-tune，π0.5 60k；同 RTX PRO 5000。 |

## 3. FocusVLA: Future-Intent Guided Dynamic View Routing for Vision-Language-Action Models

- **来源：** [arXiv](https://arxiv.org/abs/2610.31423) · [PDF](https://arxiv.org/pdf/2610.31423) · [Hugging Face](https://huggingface.co/papers/2610.31423)
- **发布日期：** 2026-10-22（近 7 天补充；超出严格窗口 6 天）
- **作者：** Huixin Xu, Ziya Yu, Peng Li
- **机构/单位：** 1 Nanjing Institute of Software Technology; 2 Institute of Software, Chinese Academy of Sciences; 3 University of Chinese Academy of Sciences, Nanjing; 4 Nanjing University of Posts and Telecommunications 5 Hohai University
- **领域标签：** manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** FocusVLA 在 π0.5 上增加 Future Intent Bridge 与 action-side step-wise view router，用未来动作意图动态协调 global/local cameras，在 RoboTwin 2.0 和真实 Piper 上分别比 π0.5 提高 10.10pp 与 13.3pp。
- **核心 insight：** 多视角 VLA 的问题不只是融合不足，而是早期形成的 view dependency inertia 会延续到后续阶段；预测未来 interaction intent 并逐 action-step 路由视图，能让规划阶段偏 global、接触阶段偏 local。

### 方法要点

- 以 π0.5 multi-view VLA 为 backbone，用短期 action history、robot state 和 vision-language context 预测未来 H=30 步 local-interaction intent。
- 从 end-effector 速度、路径、轴向主导性和 gripper closing 自动生成 trajectory-derived weak labels。
- 将 intent 聚合为 chunk-level token，并映射为每步 global/local 权重，在 action backbone 内分别 cross-attend 两类视图后融合。
- 先做 5K-step intent warm-up，再联合 action loss 与 weighted BCE intent loss；模块增加 70.13M 参数。

- verifier 在 development episodes 比较 repaired failures 与 regressed successes；选定 harness 在 held-out test 前冻结。

## 5. VLA-Stem: A Lightweight Safety Mechanism for Vision-Language-Action Models via Reinforcement Learning

- **来源：** [arXiv](https://arxiv.org/abs/2610.37378) · [PDF](https://arxiv.org/pdf/2610.37378)
- **发布日期：** 2026-10-27（近 7 天补充；超出严格窗口 1 天）
- **作者：** Bojun Zou, Wenhao Yu, Jiaohao Li, Jiaxuan Lin, Guanting Ye, Haohan Geng, Weihao Yu, Yanyong Zhang, Jianmin Ji
- **机构/单位：** 1University of Science and Technology of China (USTC); 2Peking University (PKU); 3University of Macau (UM)
- **领域标签：** manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** VLA-Stem 把冻结 VLA action chunk 转为 trajectory reference，再由 1.75M 参数 PPO student 根据 proprioception 与局部障碍实时改动作，通过 trajectory-level guidance 和 privileged teacher distillation 同时保任务意图与避障。
- **核心 insight：** 安全层若只逐步修正 nominal action，容易让后续 VLA chunk 与实际状态错位；把整段 reference 当作可放松时间对齐、但保持前向进度的空间走廊，能让局部绕行/等待后重新接回任务轨迹。

### 方法要点

- 每 h=8 控制步查询一次 frozen VLA，将 action chunk 积分成相对 end-effector SE(3) reference trajectory。
- Stem policy 联合输入 reference、robot state 与 obstacle boxes，逐控制步输出 executable action。
- trajectory-level reward 将当前 pose 投影到 reference segments，用 non-decreasing forward corridor 保持进度，同时允许 timing relaxation。
- privileged teacher 额外读取 target-object state，经 trajectory→static→dynamic curriculum 训练，再用 PPO + KL distillation 得到部署 student。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| ManiSkill 三任务×static/dynamic 六个 constrained settings，每 setting 3,200 episodes | Average collision-free task success（SUCC） | VLA-Stem 52.8% | 最强 safety baseline 23.7% | +29.1pp（约 2.23×） | PDF p.1 Abstract 与 p.5 Table I；SUCC 定义为完成且无 collision/constraint violation。 |
| Object Stowing trajectory-guidance ablation，normal/static/dynamic | Average Success Rate | trajectory-level guidance 63% | step-wise action alignment 30% | +33pp | PDF p.7 Table III 与紧邻正文；三场景均值。 |
| UR7e real robot，Object Stowing + Stacking，static/dynamic，15 trials/task/scenario | Collision rate / task success | VLA-Stem collision 20–40%，success 47–60% | π0.5 collision 73–100%，success 0–20% | collision 至少 -33pp；success 至少 +27pp | PDF p.7 Fig. 5 与 p.8 Sec. IV-C；图中每任务具体柱值未列表化，使用正文明确区间。 |

## 6. Agentic World Action Models

- **来源：** [arXiv](https://arxiv.org/abs/2610.30136) · [PDF](https://arxiv.org/pdf/2610.30136) · [Hugging Face](https://huggingface.co/papers/2610.30136)
- **发布日期：** 2026-10-21（近 7 天补充；超出严格窗口 7 天）
- **作者：** Zhuoyang Liu, Dantong Niu, Botong Zhang, Boning Shao, Jing Wang, Ruijie Zheng, Yuvan Sharma, Runyu Lu, Jiaming Liu, Renrui Zhang, Roei Herzig, Yutong Bai et al.
- **机构/单位：** 1 UC Berkeley 2 NVIDIA 3 University of Pennsylvania; Primitive APIs
- **领域标签：** dexterous, manipulation, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** AW-0 在 Mixture-of-Transformers 中联合去噪 code、future video 与 action 三条流，让可复用 skill program 同时充当 world-action prediction 的语义计划，并在 gate 通过时接管部分控制步骤。
- **核心 insight：** 视觉动力学与 agentic code 的组合性互补：code 结构化长任务并复用 skill，video/action 把计划锚定到物理变化；同一去噪过程比串行文本→动作更快且误差更少。

### 方法要点

- 三 expert MoT 分别处理 code diffusion、video latent flow matching 与 action flow matching，blockwise causal 顺序 C→V→A。
- 自动标注 pipeline 用 coding agents 写 subtask programs、协调并提炼 routine，冻结 23 个 YAM 与 27 个 egocentric-human skills。
- code expert 读取多视图、instruction、state 与 program-slice memory；默认 code 只作为 action expert 的 plan condition。
- hybrid mode 对 code slice 做 stage、dependency、syntax/whitelist/vacuity gates；通过时执行 primitives，否则执行同次 forward pass 的 action chunk。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
