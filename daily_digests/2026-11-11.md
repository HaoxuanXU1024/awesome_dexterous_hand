## 1. Thermo-VLA: A Thermal-Aware Vision-Language-Action Model with Gated Residual Modulation for Robotic Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2611.11981) · [PDF](https://arxiv.org/pdf/2611.11981)
- **发布日期：** 2026-11-09（近 7 天补充；超出严格窗口 2 天）
- **作者：** Jingxuan Chen, Junshi Luo, Chencheng Dong, Xiaojian Nie, Tongge Huang, Qiang Huang
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** Thermo-VLA 不把 thermal image 当作普通视觉帧，而是分解 cold/hot attributes，并用 language-conditioned gate 将它们残差注入 RGB tokens 来完成温度推理操控。
- **核心 insight：** 温度任务的难点是 task-dependent attribute selection：相同热图中的冷、热与机器人自身热源不能靠简单 token concatenation 区分，文本门控残差能让 thermal evidence 按指令选择性影响动作。

### 方法要点

- 以 scene background intensity 校准 thermal frame，并分解为 cold/hot 两个互补 attribute views。
- 共享 SigLIP thermal encoder 与 RGB projector，把两支 thermal tokens 映射到 RGB token layout。
- Text-Gate Cross-Attention 由 instruction token 预测 α/β，再把 cold/hot tokens 作为 residual 注入 head-camera RGB token。
- Gemma multimodal backbone 与 π0.5-style flow-matching action expert 生成 7-DoF arm + gripper continuous action chunks。

### 实验与结果

|---|---|---|---|---|---|
| Unitree G1 真实双臂，6 tasks，1,307 expert demos，每 instruction 20 trials | Success Rate（4 个 temperature-dependent tasks 平均） | 0.86 | π0.5 (RGBT) 0.68；ThermoAct 更低 | +18pp 对 π0.5 (RGBT) | PDF p.4–5 Table I–II 与 Abstract；逐行核对 Task II/IV/V/VI。 |
| unseen objects / illumination / unseen tablecloth generalization | Average Success Rate | 0.79 / 0.76 / 0.79 | π0.5 (RGBT) 0.64 / 0.68 / 0.72；ThermoAct 0.38 / 0.35 / 0.34 | +0.15 / +0.08 / +0.07 对 π0.5 (RGBT) | PDF p.6 Table III；核对 Target Generalisation 与 Scene Generalisation 分组。 |
| RGBRes transfer：4 个 colour-conditioned simulation/real tests | Average Success Rate | 0.775 | π0.5 0.572 | +20.3pp | PDF p.7 Table V 与紧邻正文；核对四列 task 与两行 method。 |

## 2. VLA Adaptation with Real and Simulated Data: A Case Study on Robotic Chess

- **来源：** [arXiv](https://arxiv.org/abs/2611.12676) · [PDF](https://arxiv.org/pdf/2611.12676)
- **发布日期：** 2026-11-09（近 7 天补充；超出严格窗口 2 天）
- **作者：** Matěj Kripner, Milan Straka
- **机构/单位：** Charles University, Faculty of Mathematics and Physics
- **领域标签：** foundation_models, manipulation, robot_learning, vla
- **灵巧手相关：** 否
- **一句话概括：** 这篇 chess case study 系统量化 π0.5 下游适配：sim data 与 update 都有效，checkpoint 必须先 cool-down，sim pretraining 尤其能救低数据 real-arm finetuning。
- **核心 insight：** VLA adaptation 最容易被 offline loss 与未冷却 checkpoint 误导；高置信闭环结论需要在可重复 simulator 中做大样本 rollout，并把 sim pretraining 视为 real data 的初始化而非替代。

### 方法要点

- 构建 SO-101 MuJoCo twin 与 randomized scripted expert，模拟 teleoperation 的 tempo、误差、纠正、抓取失败重试。
- π0.5 接收双相机、6 joint positions、棋盘格语言指令和当前 stage，输出 50-step joint-target chunk 并预测 stage transition。
- 对 100–10k sim demos 与 1k–237k updates 做 constant-rate trunk + 最后 10% learning-rate cool-down，并以 1,000 closed-loop trials 评估。
- real arm 用 32/128/256 demos 比较 base 与 sim-initialized policy；另测试 filtered BC、RECAP variants、automatic coach 与 residual PPO。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| MuJoCo chess king move，10k demos，1,000 trials/model | Success Rate | 64.1%（237k updates, cooled down） | 60.2% at 165k；48.9% constant-rate/no cool-down；57.0% SWA | 对同预算未 cool-down +11.3pp；正文某 branch 对起点 checkpoint 最大 +31pp | PDF p.5 与 p.11 Table 1；核对 demos、updates、success 三列。 |
| SO-101 真机，128 demonstrations，25 trials/model | Task Success | sim-initialized 18/25 = 72% | base π0.5 initialized 2/25 = 8% | +64pp | PDF p.7–8 Fig. 9 与 p.11 Table 2；核对 128 demos/45k updates 行。 |
| 1K demos + 1K policy rollouts，79k updates，1,000 sim trials | Success Rate | Filtered BC 32.9%；best listed coached RECAP 34.7% | demonstrations-only BC 29.9% | +3.0pp / +4.8pp，处于作者认定的 evaluation noise/跨 schedule 不一致范围 | PDF p.11 Table 1 与 p.13；论文明确给出 negative result，未宣称稳定提升。 |

## 3. Toward the Era of Agentic Embodied Intelligence

- **来源：** [arXiv](https://arxiv.org/abs/2611.09124) · [PDF](https://arxiv.org/pdf/2611.09124) · [Hugging Face](https://huggingface.co/papers/2611.09124)
- **发布日期：** 2026-11-06（近 7 天补充；超出严格窗口 5 天）
- **作者：** Chao Liang, Ke Chen, Fengxiaoxiao Li, Shibo Huang, Yufeng Sun, Zhaokai Yin, Jianhuan Lai, Haozhe Feng, Chenghuan Jia, Zhipeng Zhang
- **机构/单位：** AutoLab, School of Artificial Intelligence, Shanghai Jiao Tong University; Research Lab, Anyverse Dynamics
- **领域标签：** embodied_ai, foundation_models, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** A2-MEAS 用 MetaBrain、diagnostic agents 与 learned correction code/Adapter，把语言、空间证据、执行历史和 base action proposal 转成固定权重下的在线纠错。
- **核心 insight：** 长时程 embodied agent 不应把所有推理都放进高频 policy，也不应只靠外部 VLM 重规划；可把高层诊断压缩成结构化 correction code，在 action expert hidden state 中做 residual adjustment。

### 方法要点

- A2-WLA 以 vision-language backbone、motion-aware visual history、multiview latent world model 和 flow-matching action expert 生成 chunks 与 local-phase progress。
- MetaBrain 维护 full task goal、诊断异常并发出 recovery instruction；grounding agents 提供 perceptual/spatiotemporal/interaction evidence。
- condition encoder 融合 correction language、structured grounding、long execution history 与 fresh base proposal，Adapter 在每个 flow step 调整 hidden state。
- 部署只执行 chunk prefix，并用共享 execution record 反复观测、验证、暂停或恢复；policy weights 保持固定。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| BEHAVIOR 2026 public set，100 tasks，1,000 episodes | Q-score / Complete-task Success | A2-MEAS 0.6411 / 45.40%（454/1,000） | multi-model A2-WLA 0.6040 / 40.60%；single shared model 0.4597 / 27.20% | 对 multi-model +0.0371 Q、+4.8pp | PDF p.27 Table 5 与 p.3；核对 1,000 episodes、88-task coverage。 |
| RoboTwin 2.0，50 bimanual tasks，Clean + Randomized | Average Success Rate | 完整系统 95.05%；A2-WLA 93.98% | 公开 reference protocols 异质，论文仅作参考比较 | +1.07pp 对 base action model | PDF p.30 Table 8 与 Abstract；核对 Clean/Randomized 平均。 |
| 12-task fixed-policy Adapter subset，120 episodes/config | Q-score / Success | Full Adapter 0.6108 / 52.50% | A2-WLA without Adapter 0.5310 / 41.67% | +0.0798 Q / +10.83pp | PDF p.37–38 Table 12；核对 condition ablations 与相同 frozen A2-WLA。 |

## 4. Open-HumanWAM: An Open Recipe for Scaling Human and Robot Experience for Embodied Foundation Models

- **来源：** [arXiv](https://arxiv.org/abs/2611.06817) · [PDF](https://arxiv.org/pdf/2611.06817) · [Hugging Face](https://huggingface.co/papers/2611.06817)

- **作者：** Juncheng Ma, Jiaxin Li, Jiankai Tu, Bo Liang, Guodong Lv, Yufan Deng, Junzhe Tang, Liangzhu Yang, Chen Bian, Shukai Gong, Yintianrun Zhang, Zicong Cao et al.
- **机构/单位：** PKU, NUS, MIT, UCSB, NVIDIA
- **领域标签：** embodied_ai, foundation_models, manipulation, robot_learning

- **一句话概括：** Open-HumanWAM 给出从 100 到 50,000 小时 egocentric human pretraining、再扩展到 human–robot hybrid training 的开放配方，并发布 HumanWAM-Vanilla/Goal。
- **核心 insight：** 人类视频对机器人不仅提供规模，更提供任务与场景多样性；统一动作表示、cross-source alignment 和 visual-goal conditioning 能把这种多样性转化为 post-training 泛化与 zero-shot 执行。

### 方法要点

- HumanWAM-Goal 基于 Cosmos3-Nano-16B，使用 49-D hybrid action space、goal image conditioning 与 joint video-action rectified-flow sampling。
- hybrid 系列把 robot data 固定为 14,618 h，再加入 15,901/45,938 h human data；RoboTwin post-training 用 50 clean demos/task。

## 5. PAIR: Proprioception-Aligned Image-Ray Representations for Viewpoint-Robust Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2611.11798) · [PDF](https://arxiv.org/pdf/2611.11798)
- **发布日期：** 2026-11-09（近 7 天补充；超出严格窗口 2 天）
- **作者：** Sung-Wook Lee, Xuhui Kang, Dylan Losey, Yen-Ling Kuo
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** manipulation, robot_learning, vla
- **灵巧手相关：** 否
- **一句话概括：** PAIR 用 robot proprioception 对齐 joint image-ray representations，使 Diffusion Policy 与 SmolVLA 在相机视角变化下学习 task-state invariant、projection-aware features。
- **核心 insight：** camera ray 只告诉模型像素从哪里看，proprioceptive contrastive alignment 只约束状态相似；两者结合才能避免把 viewpoint appearance 当成 task state，也避免跨视角产生错误对应。

### 方法要点

- 把每个 image patch 与 end-effector-relative、robot-base-relative Plücker rays 共同编码，作为轻量 camera geometry conditioning。
- 用 joint position/quaternion distance 构造 proprioceptive similarity，对 image-ray features 做 supervised contrastive alignment。
- PAIR 作为 auxiliary objective 接到 SigLIP2 Diffusion Policy 或 post-trained SmolVLA，不改变部署时 action interface。
- single-view policy 可在训练时利用额外 camera views 作为 contrastive targets，推理仍只消费一个 view。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| LIBERO 4 suites，SmolVLA，3 seeds，500 rollouts/suite | Average Success Rate | PAIR + ray 88.9% | BC + ray 83.3%；TCN + ray 84.0%；PAIR without ray 83.9% | +5.6pp / +4.9pp / +5.0pp | PDF p.6 Table IV；核对 Object/Goal/Spatial/Long/Average 与 w/wo ray。 |
| MimicGen + ALOHA Transfer，Diffusion Policy，3 seeds，200 rollouts/checkpoint | Success Rate | PAIR+ray：Square 24.4%、3-Stack 45.1%、3-Pc 29.1%、ALOHA 42.3%（single-view） | BC without ray：13.4%、34.1%、18.1%、35.2% | +11.0pp、+11.0pp、+11.0pp、+7.1pp | PDF p.6 Table III；核对 Single/Multi 分组及四个 benchmark。 |
| FR3 真机，3 tabletop tasks，100 demos/task，30 rollouts/task，unseen camera poses | Subtask / Final-task Success | 76.7% / 57.8% | BC without ray 53.4% / 31.1% | +23.3pp / +26.7pp | PDF p.6 Fig. 4 与正文；核对三任务均值及 camera resampling protocol。 |
