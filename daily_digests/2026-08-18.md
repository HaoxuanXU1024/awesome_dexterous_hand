## 1. DreamX-Phi 1.0: Action-Conditioned Video World Model for Robotic Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2608.13489) · [PDF](https://arxiv.org/pdf/2608.13489) · [Hugging Face](https://huggingface.co/papers/2608.13489)
- **发布日期：** 2026-08-13（近 7 天补充；超出严格窗口 5 天）
- **作者：** DreamX Team, Rui Chen, Xiangxiang Chu, Geng Li, Jifan Li, Qingfeng Shi, Datao Tang, Jing Tang, Jun Wang, Pengfei Zhang
- **机构/单位：** available.1; World models provide a scalable way to evaluate candidate actions before physical execution. By predicting; 1Model weights and inference code will be made publicly available after the WorldArena 2.0 IROS Challenge concludes.
- **领域标签：** manipulation, world_models
- **灵巧手相关：** 否
- **一句话概括：** DreamX-Phi 1.0 以 arm-grouped PRoPE、robot-only flow cue、depth/object supervision 和 DMD distillation 构建可遵循双臂 SE(3) 动作轨迹的视频 world model。
- **核心 insight：** 动作条件视频的关键不只是逼真，而是让每只机械臂沿指定 3D 轨迹运动并保持小物体接触一致性；论文将几何动作约束、图像平面运动线索、场景深度与 object-relational teacher 拆成互补监督。

### 方法要点

- 以 Wan2.2-TI2V-5B 为 backbone，输入 observed RGB、language instruction 与外部给定的双臂 end-effector poses/gripper states，预测 future RGB video。
- 把每只手臂的相对 SE(3) 变换分配到固定 attention heads，经 PRoPE 作用于 Q/K/V；gripper scalar 另作 per-arm bias，并加入 robot-only optical-flow cue。
- 用 SAM3 mask 重加权 object RGB loss、Depth Anything 3 depth latent branch 与 frozen V-JEPA Gram-relation loss 约束几何/物体一致性，最后用 DMD+adversarial training 蒸馏 few-step student。

## 2. Reflex: Enabling Fast and Predictive Vision-Language-Action Models for Reaction-Critical Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2608.14379) · [PDF](https://arxiv.org/pdf/2608.14379)
- **发布日期：** 2026-08-14（近 7 天补充；超出严格窗口 4 天）
- **作者：** Yuxuan Chen, Wanruo Zhang, Xiao Li
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** ReflexVLA 把 latent future prediction、multi-frame temporal fusion 与 CUDA Graph acceleration 合并到 1B VLA，并用显式注入 latency 的 ReflexBench 评估反应关键型动态操作。
- **核心 insight：** dynamic manipulation 的失败同时来自看不见未来与算得太慢；未来 latent target 提供 anticipation，vision-backbone 内的 temporal fusion 提供 motion history，而 batched encoding/CUDA Graph 把这些能力转化为更短 perception-to-action delay。

### 方法要点

- ReflexBench 含 6 个 dynamic tasks，并把 simulator stepping 与 robot control 解耦；按 Real-Time Factor 注入真实 inference latency，分别支持 synchronous 与 asynchronous execution。
- ReflexVLA 在 VLA-Adapter backbone 上追加 H 个 future tokens，用 frozen DINOv3 future features 的 masked cosine loss 与 action loss 联合训练。
- 对两帧历史的 intermediate ViT features 做 causal temporal attention，只把 fused current-frame tokens 送入 language model；部署时合并 multi-view/frame visual encoding 并 replay 整条 CUDA Graph。

## 3. Evolve Vision-Language-Action Model into an Agent with On-the-fly Tool-use

## 4. S2-HWM: Sparse Event-Structured Hierarchical World Model for Long-Horizon Surgical Robot Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2608.13103) · [PDF](https://arxiv.org/pdf/2608.13103)
- **发布日期：** 2026-08-13（近 7 天补充；超出严格窗口 5 天）

- **机构/单位：** 1Shenzhen Institutes of Advanced Technology, Chinese Academy of Sciences; 2University of Chinese Academy of Sciences
- **领域标签：** manipulation, world_models
- **灵巧手相关：** 否
- **一句话概括：** S2-HWM 从 primitive latent trajectory 学习 sparse event evidence，用它同时调度 manager goal 更新并训练 Event Transition Model，以 variable-duration event rollout 延长 long-horizon value bootstrap。
- **核心 insight：** 长时程 surgical manipulation 的关键边界不是固定 step 或人工 stage，而是随 contact/state 演化的事件；同一 event evidence 若同时决定何时换 high-level goal 与如何跨事件预测，就能把 hierarchical control 与 world-model credit assignment 对齐。

### 方法要点

- DreamerV3 RSSM 在 primitive step 更新 z/h，并维护稀疏门控 interaction context m；straight-through binary gate g 提供 event evidence。
- manager 在 accepted boundary 选择 discrete latent code，worker 在下一 boundary 前持续以其 embedding 为条件执行九种 primitive actions；manager 与 ETM 可对同一 evidence 使用各自 acceptance rule。
- ETM 直接预测 next-boundary stochastic state、segment duration 与 accumulated reward；从 primitive imagination 终点递归 K 个 event transitions，和 short-horizon bootstrap 加权形成 manager target。

## 5. Decoding Task Progress from VLA Representations

- **来源：** [arXiv](https://arxiv.org/abs/2608.13474) · [PDF](https://arxiv.org/pdf/2608.13474)
- **发布日期：** 2026-08-13（近 7 天补充；超出严格窗口 5 天）
- **作者：** Atiksh Bhardwaj, Edward Weiyi Duan, Prithwish Dan, Wei-Chiu Ma, Preston Culbertson
- **机构/单位：** Cornell University
- **领域标签：** manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** 该文用线性 probe 从 pi0.5 residual stream 解码 task progress，并把 progress stagnation 变成无需 OOD labels 的 runtime detector，同时证明可读特征不等于可操控特征。
- **核心 insight：** VLA 内部已经编码了随任务推进变化的语义信号，但 naive probe 可能只读视觉时间线索；counterfactual instruction training 能恢复 language sensitivity，却仍不能沿 probe direction 驱动 action，说明 decodability、strong decodability 与 steerability 必须分开验证。

### 方法要点

- 从 PaliGemma/pi0.x 各层 residual activations 提取 mean-pooled embeddings，以 trajectory normalized time remaining 作为 progress label，训练 L1 linear probes。
- 用 target-noun swap 构造 T_lang counterfactual，通过 within-pair hinge 加 BCE anchor 训练 language-sensitive probe；再沿 probe direction 注入 tau_boost 检验 causal steerability。
- 运行时将 decoded progress 与 instruction-conditioned expected progress 比较，进度停滞即形成 V_tau OOD score；只用 ID rollouts 校准，不需要 OOD examples。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
