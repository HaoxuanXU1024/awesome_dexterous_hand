## 1. Robot Learning with Vision-Language-Action Models for Agricultural Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2610.26717) · [PDF](https://arxiv.org/pdf/2610.26717)
- **发布日期：** 2026-10-19（近 7 天补充；超出严格窗口 2 天）
- **作者：** Hamid Hafezi, Javad Mohammadpour Velni, Mohammadreza Davoodi
- **机构/单位：** 论文首页未可靠提取
- **领域标签：** manipulation, robot_learning, sim_to_real, vla
- **灵巧手相关：** 否
- **一句话概括：** 该工作在 MuJoCo 番茄场景中用 200 条示范适配 Octo 与 π0.5，再用 50 条 FR3 实机示范微调，显示 π0.5 在视角/空间偏移与未见植株上比 Octo 更稳。
- **核心 insight：** 农业 manipulation 的主要难点是植物几何、遮挡和接触的变化；通用 VLA 可以通过 simulation-first、少量 real-data adaptation 获得可用行为，但本实验也表明额外 proprioception 可能诱发对训练构型的相关性依赖，未必改善视觉主导的 reaching-and-grasping。

### 方法要点

- 构建含 9 种 tomato plants 的 MuJoCo greenhouse-like 环境，使用 FR3 arm + gripper、primary/wrist cameras 和 joystick teleoperation 收集 200 条模拟示范。
- 分别适配 Octo-Base（diffusion action head，history 2，chunk 4）与 π0.5（flow matching，current frame，chunk 10、执行前 5 步），并训练有/无 informative proprioception 的版本。
- 模拟侧评估 in-distribution、viewpoint/spatial shift、OOD unseen plant 三种条件，每模型配置各 25 trials；实机侧再以 50 条示范微调并在 FR3 上各测 10 trials。
- 统一用 damped Jacobian differential IK 执行 end-effector delta，并以 full success=100、reach-only=50、failure=0 计算 task-performance score。

## 2. Vision-Language-Delta-Action: Learning Compact Deltas as Actionable Transition Interfaces for Robotic Manipulation

- **来源：** [arXiv](https://arxiv.org/abs/2610.25874) · [PDF](https://arxiv.org/pdf/2610.25874) · [Hugging Face](https://huggingface.co/papers/2610.25874)
- **发布日期：** 2026-10-19（近 7 天补充；超出严格窗口 2 天）
- **作者：** Lingsen Zhang, Wei Li, Jie He, Henghua Zhang, Kai Mo, Shiyong Li, Yanpeng Wang, Rui Shao
- **机构/单位：** 1Harbin Institute of Technology, Shenzhen 2Baidu, Inc. 3Shenzhen Loop Area Institute
- **领域标签：** embodied_ai, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** VLDA 不预测完整未来画面，而学习稀疏、可执行的 latent Delta，并用它为 action flow 提供噪声偏置与 prefix conditioning，在 LIBERO-Plus、RoboTwin 2.0 和双臂实机长时程任务上提升泛化。
- **核心 insight：** 机器人动作真正需要的是任务相关的“哪里、怎样改变”，而非静态背景占多数的完整 future state；用 local transition selection 保留交互变化、global anchor 保持总体趋势，再对齐 action manifold，可把未来信息变成直接可消费的 action prior。

### 方法要点

- World Expert 从当前 primary-view 与 future-view 的 V-JEPA 2 features 构造 dense difference，LT-Filter 选 top-K 高变化 tokens（K=64）并降维成 Delta target。
- GT-Anchor 对未来 feature 做粗粒度 pooling，为 Delta 提供 scene-level transition consistency，避免只关注局部变化。
- DDAR 通过 Delta-to-Action Manifold Grounding 将 Delta tokens 与当前 action chunk 的正样本对齐、与同轨迹其他时段负样本做 InfoNCE。
- Delta-Seeded Action Flow 把 mean-pooled Delta 同时变为 action-noise bias 与 prefix token；采用 transition pretraining 后 joint optimization 的两阶段训练，推理无需 future image。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| LIBERO-Plus，standard LIBERO 训练后 zero-shot，10,030 rollouts | Average Success Rate | VLDA 84.5% | π0.5 73.6%；GuidedVLA 75.4% | +10.9pp / +9.1pp | PDF p.8 Table 1，逐列核对 7 个 perturbations、4 个 task suites 与 Avg.。 |
| RoboTwin 2.0 selected hard/randomized tasks，clean-only training | Average Success Rate | VLDA 62.9% | π0.5 42.7% | +20.2pp | PDF p.10 Table 2；完整 50-task 结果在 Appendix Table 8，overall 50.86% vs π0.5 43.84%。 |
| GALAXEA R1 Lite，4 个长时程任务，25 trials/task | Average complete-task success | VLDA 73.0% | π0.5 56.0%；OpenVLA-OFT 16.0% | +17.0pp / +57.0pp | PDF p.10 Table 3，Avg. 按每任务 final checkpoint success 取平均。 |
| LIBERO transition-paradigm ablation | Average Success Rate | VLDA 98.5% | full-future prediction 97.8%；w/o transition pretraining 97.3%；w/o Delta-seeded action flow 97.2% | +0.7pp / +1.2pp / +1.3pp | PDF p.11 Table 4 与 p.12 ablation discussion。 |

## 3. HAF-VLA: Hierarchical Action Flow Framework for Humanoid Vision-Language-Action Control

- **来源：** [arXiv](https://arxiv.org/abs/2610.26584) · [PDF](https://arxiv.org/pdf/2610.26584)
- **发布日期：** 2026-10-19（近 7 天补充；超出严格窗口 2 天）
- **作者：** Langzhe Gu, Chengkai Hou, Meng Li, Xinhua Wang, Xinyuan Lv, Shuanghao Bai, Guangrun Li, Jingyang He, Ziluo Ding, Zhiyuan Xu, Ning Ding, Kuan Cheng et al.
- **机构/单位：** 1State Key Laboratory of Multimedia Information Processing, School of Computer Science,; Peking University; 3Nankai University 4Xi’an Jiaotong University 5Tsinghua University
- **领域标签：** humanoid, manipulation, vla
- **灵巧手相关：** 否
- **一句话概括：** HAF-VLA 把 humanoid whole-body action flow 按 locomotion/head→waist→arms/hands 三阶段累积生成，并用 cross-stage KV cache 传递已完成的动作计划，在六项真实长时程任务上把平均 normalized score 从 π0.5 的 53.3% 提到 68.3%。
- **核心 insight：** humanoid locomotion、posture 与 manipulation 存在明确运动学依赖；先稳定 base/head，再调 waist workspace，最后生成 arms/hands，并允许后级小幅修正前级计划，比一次性在 32-D whole-body space 中去噪更可靠。

### 方法要点

- 继承 π0.5 的 vision-language prefix encoder 与 action expert，加入 learnable stage embeddings；动作 horizon 100、模型维度 32，其中 26 个有效控制维度。
- Stage 1 激活 locomotion/skill/head，Stage 2 累加 waist，Stage 3 累加 arms/hands；所有阶段共享 action expert 和全局动作空间。
- 每个非最终阶段完成 10-step flow denoising 后，把 clean action 重新编码为 self-attention KV cache，供后续阶段条件化与 soft refinement；训练用 ground-truth masked actions 做 teacher-forced cache。
- 部署时执行 Stage 3 的前 40 步后 receding-horizon 重规划，locomotion/waist 交给 RL low-level controller，arm/hand/head 使用 position control。

### 实验与结果

| Benchmark / setting | Metric | Result | Baseline | Relative gain | Evidence |
|---|---|---|---|---|---|
| 六项 Tian Gong 2.0/3.0 真实 loco-manipulation tasks，10 rollouts/task | Average normalized task score | HAF-VLA 68.3% | π0.5 53.3%；GR00T N1.7 37.8%；Cosmos Policy 25.0%；ACT 25.6% | 对最强 baseline π0.5 +15.0pp | PDF p.7 Table 1，核对六任务与 Average 列；不是 full-task success rate。 |
| Box Carry controlled ablation，10 real-robot rollouts | Normalized task score | HAF-VLA 86.7% | π0.5 10-step 70.0%；π0.5 30-step 30.0%；All-Joint 73.3% | +16.7pp / +56.7pp / +13.4pp | PDF p.8 Table 2；30-step baseline 与三阶段总 denoising updates 匹配但计算并非完全等价。 |
| Box Carry cross-stage cache ablation | Normalized task score / safety | HAF-VLA 86.7% | No-Cache-Train 50.0%；No-Cache-Deploy 与 Zero-Cache-Deploy 均 Unsafe | 训练时移除 cache -36.7pp；推理时破坏 cache 导致 unsafe motions | PDF p.8 Table 2 与紧邻正文。 |
| Box Carry，30 cm target-table shift | Normalized task score / drop from unperturbed | HAF-VLA 73.3%，drop 13.3pp | π0.5 40.0%，drop 30.0pp | +33.3pp，且性能下降少 16.7pp | PDF p.9 Table 3，核对 score 与 drop 两列。 |

## 4. SafeDriveVLA: Navigation-Conditioned World Model Dreaming for Conflict-Aware End-to-End Autonomous Driving

- **来源：** [arXiv](https://arxiv.org/abs/2610.20609) · [PDF](https://arxiv.org/pdf/2610.20609) · [Hugging Face](https://huggingface.co/papers/2610.20609)
- **发布日期：** 2026-10-14（近 7 天补充；超出严格窗口 7 天）
- **作者：** Shaoyuan Xie, Zihan Zhang, Jingxuan Wang, Jiashu Qu, Xiaoqing Liang, Lingdong Kong, Junchi Lu, Henrik I. Christensen, Qi Alfred Chen
- **机构/单位：** 1UC Irvine 2UC San Diego 3University of Cincinnati 4National University of Singapore
- **领域标签：** navigation, vla, world_models
- **灵巧手相关：** 否
- **一句话概括：** SafeDriveVLA 先显式预测 STRICT/CAUTIOUS/FALLBACK 驾驶模式，再用“严格执行导航指令”的 latent world-model rollout 判断该指令在当前场景是否安全。
- **核心 insight：** 仅把安全偏好写进 VLA 会让模型普遍保守；先想象严格执行指令的后果，再由独立 mode token 决定执行、谨慎执行或覆盖指令，能把 navigation following 与 conflict awareness 从同一动作解码中解耦。

### 方法要点

- 用专家轨迹的运动学规则为每帧生成 STRICT、CAUTIOUS、FALLBACK 标签，并在动作 token 前监督输出 mode token。
- 冻结 V-JEPA 2 ViT-L target encoder，以两帧编码运动信息，训练 action-conditioned Transformer 在 2.5 s、2 Hz 上预测 latent future。
- 将导航信号映射到 meta-command action anchor，沿该 anchor rollout 5 步；InternVL3-1B + LoRA 结合 dreamed latents，以 2048 个 motion primitives 和 lateral PID 输出轨迹。

| CARLA-F，纯自然语言指令，closed loop | Navigation Completion Rate (weighted Avg.) | 83.0% | best SimLingo variant 55.6% | +27.4pp；lane-change left/right 从 0/0 提至 63.6/72.4% | PDF p.8 Table 4；Avg. 排除 speed，按指令数加权。 |
| B2D-C，instruction-scene conflict | DS / SR / collisions / traffic violations / out-of-route | 85.9 / 67.3% / 38 / 9 / 4 | SimLingo-Safe 72.8 / 38.0% / 60 / 61 / 11 | +13.1 DS / +29.3pp SR；碰撞 -36.7%，交通违规 -85.2%，偏航 -63.6% | PDF p.9 Table 5。 |
